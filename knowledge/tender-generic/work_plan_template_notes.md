# Work Plan submission template notes (generic)

This generic pack does not ship a proprietary DOCX. Use this note until the project binds a real Work Plan template in `bindings.json`.

## Minimum formal content

- Cover / project identification
- Understanding of the works
- Proposed methodology (package-by-package)
- Programme narrative and key milestones
- Resources (plant / labour) summary
- Quality and HSE commitments required by the tender
- Annexes: drawings references, organigram, programme exports

Replace this binding with a local `.docx` when the bid team has an approved shell.
