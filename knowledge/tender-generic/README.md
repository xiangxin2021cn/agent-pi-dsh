# Tender generic international knowledge pack

Neutral method and boundary templates for Agent Pi tender workbench (V2.6+).

| File | Role |
| --- | --- |
| `analysis_suite_depth.md` | Document-analysis depth bar: five synthesis memos (structure only, no project facts) |
| `generic_direct_cost_five_step.md` | BOQ five-step direct-cost method & depth (non-COTO) |
| `boq_unit_cost_workbook_notes.md` | Formula workbook layout (Summary / Rates / per-item sheets) |
| `boq_unit_cost_analysis_template.xlsx` | Blank demonstration workbook (no project rates) |
| `project_boundary_template.md` | Project boundary conditions worksheet |
| `methodology_depth_guide.md` | Construction methodology report depth guide |
| `work_plan_template_notes.md` | Work Plan submission structure notes (replace with local DOCX when available) |
| `cashflow_chart_notes.md` | Cash-flow / S-curve presentation notes |
| `histogram_style_notes.md` | Plant/labour histogram presentation notes |

These files constrain **structure and method depth**, not project facts. Facts must come from registered tender sources and the confirmed `project_boundary` pack.

Default profile for **new** projects is `generic-international` (see `../profiles.json`). South Africa SANRAL highway remains available as profile `sa-sanral-highway` via `knowledge/tender-sa-sanral/`.
