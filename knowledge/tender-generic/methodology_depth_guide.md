# Construction methodology depth guide (generic)

Use this as a **depth / TOC standard** for execution planning when the project is not bound to a jurisdiction-specific sample report (e.g. N2-18).

## Expected coverage (adapt to the tender)

1. Project understanding and constraints (from document analysis + project boundary)
2. Organisation and site layout assumptions (from organisation outline)
3. Temporary works and traffic / interface management (if applicable)
4. Method statements by major work package (aligned to priced BOQ chapters)
5. Programme logic and productivity basis (from BOQ planningBasis)
6. Plant and labour deployment philosophy
7. Quality, testing, and HSE hard constraints carried from tender docs
8. Risks, assumptions, and clarification items still open

## Rules

- Depth should match the **current** tender and confirmed boundary — do not copy facts from unrelated sample projects
- Prefer citing registered sources and Official Outputs paths listed in stage deliverables
- If the employer requires a branded Work Plan template, replace `work_plan_template_notes.md` via project `bindings.json`
