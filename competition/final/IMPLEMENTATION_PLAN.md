# 决赛递交版实施计划

## 目标

为参赛作品《海外工程投标及商业调研全流程AI智能 Agent 作业系统》制作可直接递交的三张 A1 竖版展板、五分钟答辩 PPT、推荐表基础填写版及配套讲稿。

## 全局约束

- 参赛人员：向鑫；申报类型：海外业务赛道。
- 展板：最多 3 张，A1 竖版，7016 × 9933 px，300 dpi，JPG；保留赛事模板顶部与页码体系。
- 视觉母版：官网浅色工程场景、海军蓝正文、蓝青渐变、并行流线汇聚、卡片与出处芯片。
- 总叙事：商业调研与工程投标双轨并行，经证据门禁汇聚为 Official Outputs，服务投标决策与中标后实施。
- 证据优先：只使用仓库中能定位的功能、流程和真实成果；隐藏个人路径及敏感信息。
- 不写入易过期或证据不足的口径：产品版本号、100+ 并行工人、1M≈800 页、无正式评测的架构优劣、未经核证的部署成本、全部开源/零许可费。
- PPT：16:9，10 页主讲 + 2 页附录，五分钟内可讲完；每页必须有视觉表达，避免大段文字。
- 推荐表：保留原模板，只填写能够确认的基本信息；单位意见、评委意见及签字盖章处留空。
- 不覆盖现有 `competition/out` 草稿；最终文件写入 `competition/final/out`。

## 任务与验证

1. 三张展板
   - 第 1 张：总命题、双轨汇聚总图、差异化价值与设计原则。
   - 第 2 张：商业调研轨 + 投标作业轨 + BOQ 五步推导 + 证据门禁。
   - 第 3 张：知识库、商业调研、施工仿真、正式成果与应用价值。
   - 验证：三张均为 7016 × 9933、300 dpi、RGB JPG；缩略图仍能读出标题与主流程。

2. 答辩 PPT
   - 10 页主讲：封面、问题、总体设计、商业调研、投标全流程、BOQ、证据门禁、真实成果、应用价值、结语。
   - 2 页附录：设计说明（1000 字以内）与证据边界。
   - 验证：文本提取无占位符；逐页渲染无裁切、重叠或低对比；至少完成一次修复后复验。

3. 推荐表
   - 从附件 2 模板创建副本，填入作品、赛道、姓名和已知单位信息。
   - 验证：模板页数、表格、页眉页脚不发生非预期变化；逐页渲染检查。

4. 交付验收
   - 核对尺寸、格式、字数、文件名、页数、敏感信息和输出清单。
   - 形成 `DELIVERY_CHECKLIST.md`，记录每项证据与结果。
