# 3.7.1 升级核查与验收

状态：开发中，尚未发布。基线为正式版 v3.7.0（322a24a77f5163ba044c128c13cc61126ed88267），不合并 3.7.0-RSI.1。

## DSH 0.1.7-alpha.1

官方发行标签 `dsh-v0.1.7-alpha.1` 指向 `c36a83ff6bb95e3f82cf79f9be7c724270a8aa61`；用户提供的 `112ce776ac785a0cda6f22e42e85575b5867ff31` 是版本更新提交。集成以经过验证的官方发行标签为准。

面向用户的主要变化：

- 会话支持置顶、归档、过滤、撤销及搜索恢复；归档运行中会话会提示受影响的任务。
- 原生执行详情按相邻思考与工具分组，可选择紧凑、详细和展开模式；工作详情、性能用量、开发者工具分别设置。
- 长命令可以转入后台，查看实时输出并停止；文件变化和任务结束后刷新预览。
- 增加只读表格预览、Office/PDF/图片缩放、系统关联程序打开文件以及并排差异比较。原生只读表格不替代本应用可编辑的 Univer。
- Agent Teams 按成员名称操作，任务板由智能体工具更新、界面只读展示。
- 修复新会话误用历史、可选插件损坏阻止启动、Windows 沙箱文件处理、图片路径编码、长工具参数阻塞和压缩预算等问题。

本应用必须适配的接口变化：V4 会话日志；自定义事件中的附件需要显式接入；DeepSeek 官方适配器改用 Messages API；预设通过插件 bundle 安装；设置改由 currentProfile 持久化；文件读取统一为 readBytes。不能只修改版本号或放宽兼容范围。

来源：[官方发行说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-alpha.1)。

## 微信工程照片

目前可以确认的代码行为：新版 dsh-im 4.23 起先保存图片原件到 Session 工作区，再生成模型预算内副本；4.25 的 `/batch` 仍只支持文字，明确拒绝图片和文件。附件保留受 TTL 控制，不能把聊天里出现的路径等同于仍存在的文件。

截图显示旧 PDF 任务进入“今日工作总结”，但截图本身不能证明具体是哪一步丢图。验收必须分别检查下载成功、实际文件与哈希、会话/聊天/批次归属、模型收到的图片、后续引用以及重启后的恢复。旧工程资料不得作为本批现场照片的替代依据。

替代方案核查：dsh-clawbot 提供微信图片输入和多会话，但需同样验证持久化与版本接口；dsh-im-bridge 的现有说明仅把文字及语音转文字送入智能体，不满足工程照片需求。优先修复既有渠道，避免让用户重新绑定后仍遇到相同问题。

来源：[dsh-im](https://github.com/xmanrui/dsh-im/releases)、[dsh-clawbot](https://github.com/tangwenhao616-netizen/dsh-clawbot)、[dsh-im-bridge](https://github.com/shaobeichen/dsh-im-bridge/blob/main/docs/weixin-setup.md)。

## 项目计划文件

用户已确认：内置 MPXJ，读取 MPP；编辑后导出 Microsoft Project XML，由 Project 打开另存为 MPP。P6 支持 XER / PMXML 读写，不承诺直接写回 MPP。

MPXJ 16.7.0 是 Java 库，许可为 LGPL，须附带许可及依赖声明，运行时在本机处理文件。已有用户目录中的 dsh-mpp-preview 0.1.0 仅作只读实现参考，不直接作为生产插件打包。

验收范围：文件栏和原生交付卡入口、任务表/甘特图、字段编辑、另存导出、重新读取核对、多项目选择、中文及编码、依赖与日历保留、来源变动冲突检测。原文件保持不变；本次编辑不暗示完整的 Project/P6 排程计算。

来源：[MPXJ 格式支持](https://www.mpxj.org/supported-formats/)、[MPXJ 许可](https://www.mpxj.org/#licensing)。
