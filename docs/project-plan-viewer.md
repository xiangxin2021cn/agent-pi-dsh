# 项目计划查看与编辑

在文件栏或 DSH 交付卡点击 MPP、XER、PMXML、Project XML 文件，可打开 MPXJ 项目计划视图。解析和导出均在本机完成。

## 浏览

- 左侧任务表与右侧甘特图按同一任务行显示，纵向滚动双向同步；各自横向滚动，拖动中间分隔条调整宽度。
- 保留源文件任务顺序和层级。点击箭头展开/折叠，搜索及筛选保留匹配任务的父级，搜索不会受折叠状态阻挡。
- 提供全部任务、关键任务、里程碑及未完成任务筛选。关键标记、里程碑、资源和工期取自源文件，没有在界面中重新计算。
- 时间刻度支持日、周、月及适合窗口；定位任务同时展开其父级、清除筛选并滚动到任务与计划日期。
- 甘特图显示汇总括号、普通/关键任务条、完成进度、里程碑和 FS/SS/FF/SF 依赖箭头。前置任务以可见任务 ID 显示，底部详情中的前置任务可点击定位。隐藏的前置任务不会被替换成其他行。
- 大型计划只渲染可见行及附近缓冲行，取消原来的每百行分页。窄窗口可切换任务表与甘特图，避免压缩任务名称。

## 修改及交付

选中任务后，在底部详情编辑名称、计划开始/完成时间、工期完成率及备注。也可双击表中任务名称编辑。支持撤销、重做及恢复原计划；任务表聚焦时可使用上下键选取、左右键展开/折叠、Enter 打开详情，Ctrl+Z/Shift+Ctrl+Z 撤销/重做。

选择“另存并校验”，确认格式和新文件名后导出。MPP 只能导出当前项目的 Project XML，不能直接写回 MPP；由 Microsoft Project 打开 XML 后另存为 MPP。P6 XML/XER 导出包含全部项目，编辑仅作用于选中的项目。后端仍使用原有的来源指纹检查、新文件名保护和重新读取校验。

任务详情与甘特图中的日期会立即反映手动修改，但工期仍显示源文件值。完成率保留原有 MPXJ 编辑语义，导出时更新剩余工期。没有实现自动排程、日历感知的工期重算、资源平衡或基线对比；实际日期及依赖关系不可在此视图中编辑。导出文件需在 Project/P6 中复核软件特有字段、日历、依赖、资源及基线。

## 实现与验证

复用现有 MPXJ 引擎及文件预览入口；界面、可见行/时间轴计算、样式和十种语言文案分开维护，不引入第三方甘特图依赖，不修改 DSH 内核或 MPXJ 运行时。

已用实际 Otjikoto 中英文 MPP 副本的 804 项任务验证：初始仅挂载 43 行；层级、搜索、双向滚动、定位、刻度、分隔条、编辑撤销/重做、Project XML 导出回读及原文件指纹保持通过。检查了 1600×1000、参考图原尺寸 2561×1508、430×932 和阿拉伯语布局，浏览器页面/控制台错误为零。前端 218 项测试、格式回读测试和新增视图计算测试通过。20,000 行的渲染窗口上界由计算测试验证，尚未声称该规模真实文件的整链路性能通过。
