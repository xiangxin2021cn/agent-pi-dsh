## P10 安装包验收入口

完整构建命令：

```powershell
powershell -NoProfile -File scripts/pack-win.ps1 -CadCleanOutput .codex-temp/cad-clean-output-release-362
```

该命令执行官方 DSH 清理及全量构建、源/运行时收据、锁文件依赖准备、完整 Office/CAD/计划校验、全新 Electron 打包、7z 载荷提取检查、NSIS 及 Windows 构建收据验证。它要求当前源码干净且有本地 v3.7.5 标签，不允许 SkipPrepare 或 ReuseUnpacked。

本地产物入口：

- `release/Agent-Pi-DSH-3.7.5-x64.exe`
- `release/Agent-Pi-DSH-3.7.5-x64.exe.sha256`
- `release/Agent-Pi-DSH-3.7.5-x64.exe.build.json`
- `.codex-temp/pack-win-3.7.5.log`

校验值读取同批次 `.sha256`；构建记录绑定源码提交、版本、DSH pin、安装包、载荷、CAD 源码/运行时及 DSH 构建字节，避免在文档里复制过期哈希。本次不对外发布，不改已发布 3.7.4 下载地址。
