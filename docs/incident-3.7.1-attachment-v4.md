# 3.7.1 附件消息回归与 DSH alpha.2 核查

核查日期：2026-09-23。本文件记录源码修复和升级判断，不表示已发布新的安装包。

## 已确认的回归

3.7.1 的附件上下文通过 `createUserMessage` 生成消息，仍使用旧来源 `{ kind: 'plugin', plugin: 'tender-host' }`。DSH V4 编码器明确拒绝 `kind: 'plugin'`，因此附件消息追加时抛出 `format v4 message requires a producer-owned source kind`。本机已安装的 3.7.1 包含这段旧代码。

源码现改为 `{ kind: 'plugin:tender-host', form: 'instructions' }`，与官方 V3→V4 对未知插件的迁移规则一致。附件投递确认同步采用新来源，仍要求消息 ID 和事务一致。提示词优化器中同一宿主的旧来源也已更新。

原有附件测试模拟消息构造和事件写入，没有经过真实官方编码器，遗漏了该兼容性回归。新增 `scripts/attachment-message-v4.test.mjs` 在修复前复现同一错误；修复后通过 PDF 附件事务认领、原生消息构造、V4 编码、恢复及投递确认。测试中的 PDF 是事务定位夹具，不验证 PDF 内容解析。
