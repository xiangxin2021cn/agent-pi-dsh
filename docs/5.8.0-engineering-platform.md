# 5.8.0 行业平台实施、验证与边界

截至 2026-10-05，以下能力已落入现有发布工作树，目标版本为 5.8.0。沿用现有分支，保留南非投标、Office/Univer、主对话及专业任务能力。本文件记录实现与专项验证，不代表最终安装包已通过验收，也不代表 5.8.0 已发布到 GitHub。

## 业务目标与共同状态

主对话理解目标、逐步澄清并反馈实际发现；工程账本保存来源版本、对象参数、数量口径、规则采用、独立覆盖目录和运行依赖；本次任务显示依据、缺口和成果；专业工作台提供阶段与工程状态入口。专业深度控制检查力度，来源、单位、重复及未知条件检查始终保留。

CAD/PDF 读取通过 `engineering.recordObservation` 登记实际观察范围，清点、读取、专业复核和验收分别记录。模型通过 `engineering_project` 登记有依据的结构化输入并执行当前启用的专业 provider，不能仅凭工具执行成功认定全图已理解。

中国工作台独立于南非 SANRAL 语义：项目制度与原始清单 → 招标要求与补遗解析 → 资格及响应证据 → 报价与工程复算差异 → 递交前人工检查。规则缺失或材料未覆盖不能显示全部通过。末阶段人工确认仅表示准备材料已复核，不代表资格结论、CA 签章或交易提交。实际地方与行业规则仍需有效来源及项目适用核验。

## 本地试用路径

在专业化工作台选择“工程图纸与算量”，登记原图后直接在主对话说明范围，例如：“先清点这套道路排水图的图纸、布局和外参，建立独立构件目录，核查管道长度；未读范围单列，计算书保留出处。”也可在普通对话使用已启用工程工具；工程记录按所属对话或绑定项目隔离。

钢筋任务先说明使用完整料表还是中国平法。平法任务需提供有授权的适用规则和项目构造条件，先检查规则内容指纹并采用固定版本，再解析标注与调用计算；没有规则或缺少节点条件时继续完成可核实部分，保留未计算组。IFC 可读取既有文件；新建模型限定为已明确尺寸与位置的矩形梁、板和代理构件。

结果可在“本次任务”和工作台查看工程记录、缺项、源文件与 IFC 预览；主对话可请求“导出当前工程计算书和 Excel，保留未知项与依据”。导出文件登记为草稿，可沿用 Office 打开。补充新图或尺寸后，先查看影响范围，复算后重新导出，旧文件保留用于追溯。

## 变更、证据与交付联动

- 源文件、对象参数或规则变更沿工程依赖使相关计算失效；只读观察不能自行把目录项改为已专业复核。
- 本次任务保留稳定的工程共同状态证据和旧运行证据。交付派生证据通过 `dependsOn` 关联当前工程状态；版本、来源真实哈希、运行状态或 provider 状态变化后，现有依赖传播将相关成果标为 `stale`。没有持久工程版本的空账本导出会明确提示尚未建立此关联。
- 原始 BOQ 以 `baselineId` 和内容指纹绑定；同编号不能替换不同来源或行内容。补遗创建新基线，旧记录保留；图算量与原量的差异单列，不覆盖招标原量。哈希不替代证书真实性核验、CA 或法律存证。
- 导出分别保存逐对象完整量、局部已知量、各口径小计、目录覆盖、钢筋组、道路分段、IFC 数量、中国响应与差异、PDF 标定依据。`null` 保留未知，0 保留数值零；过期或阻塞运行不进入当前有效小计，历史值保留。
- 卸载插件移除工具、能力或工作台注册，不删除已保存项目、流程快照、计算历史和交付；现有 Office/Univer 加载和文件打开链路保留。导出 XLSX 可交给现有 `univer_import`，HTML 可原生预览。

## 发布与实项目验收仍需完成

本地验证用 Python/IFC 运行时已可用，但其中 native 依赖的许可证、源代码及分发闭包仍需公共发布审计。不能以本地运行成功替代再分发条件核验；本文件不声明已完成 GitHub 公共发布。最终安装包构建、文件清单、冷启动、安装/升级和完整插件回归由发布流程单独记录。

完整中国实图、专业审核料单和实际加工约定尚未提供。合成算例、真实 DWG 清点与数据闭环测试不能替代实图钢筋识别准确率、漏项率和可加工性验收。不分发未经授权的图集全文，不拷贝 RebarViz 非商业许可实现。

后续实项目验收应覆盖两条完整路径：

1. 市政泵房或配套建筑：独立图纸/构件目录 → 指定范围梁柱基础及板 → 依据核验与钢筋逐组结果 → 图算/招标清单差异 → 响应与计算书 → 一次设计补遗 → 相关结果失效、复算和人工审校。
2. 道路工程：平纵横断面及排水图 → 桩号与构造范围 → 分层体积和管沟/构筑物对象 → 单位、重复与覆盖核对 → 清单差异、源图回溯和交付。

同时保留南非流程、主对话目标与阶段决策、专业深度、本次任务及 Univer 实际加载和文件打开的完整回归。专业结论由有责任的主体审阅，计算成功与客户验收、设计确认及加工批准分别记录。
