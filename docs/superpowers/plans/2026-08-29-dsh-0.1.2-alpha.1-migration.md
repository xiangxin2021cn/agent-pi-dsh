# Agent Pi DSH 3.4.0 — DSH 0.1.2-alpha.1 迁移计划

日期：2026-08-29

分支：`codex/dsh-3.4.0-dsh-0.1.2-migration`

应用版本：`3.4.0`

上游标签：`dsh-v0.1.2-alpha.1`

上游提交：`cd5ef8148158c3a752a658978873241fdf8e2bbc`

## 当前结论

3.4.0 必须按新架构重新接入，不能把 3.3.6 的内核补丁强行套到 alpha.1。旧补丁共触及 94 个路径；alpha.1 中仅 48 个路径仍存在，46 个路径已移除。实际 `git apply --check` 会安全失败且不会修改新内核；补丁文件还存在统一 diff 空白行格式问题，在旧内核上也会报 `corrupt patch`，因此它只能作为行为清单和历史证据。

3.3.6 继续作为稳定发布版。3.4.0 在本计划全部发布门禁通过前，不打包、不打标签、不覆盖官网稳定下载入口。

## 不可丢失的 Agent Pi 能力

| 能力 | 3.3.6 现状 | 3.4.0 验收要求 |
| --- | --- | --- |
| 投标控制面 | 阶段推进、BOQ 覆盖、组价前置校验、父会话接续 | 现有业务测试全绿；不得绕过真实 BOQ 和阶段门禁 |
| 本地知识库 | 知识包、模板、子目录、`.apkb`、MinerU 转表 | 导入、检索、投标任务引用和持久化行为保持一致 |
| Codex 主对话指派 | 用户可指定当前轮由 Codex 执行 | 在新 session controller 上保持显式路由，不自动继承父会话 |
| 每会话事务控制器 | 统一准备、提交、成功、失败、销毁 | 每个会话独立；失败可恢复；销毁后不得残留提交状态 |
| ChatGPT/Codex 登录 | 无 API Key 登录、状态探测、模型列表 | 优先评估官方 `subagent-codex`，保留现有桌面凭据边界和 UI |
| 模型容量 | 官方值、供应商发现值、保守估计逐字段标注来源 | 容量来源不可降级为无出处常量；未知模型保持保守策略 |
| 自动压缩 | 约 72% 自动触发；当前模型失败后可选 DeepSeek V4 Flash 兜底 | 在新 compaction API 上保留阈值、用户授权和跨供应商披露 |
| 审批与路径打开 | 审批收口、原生路径打开、父会话唤醒 | 迁移到新 controller/gateway 后逐项有回归测试 |
| 本地工具链 | Windows shell、web_fetch、AnySearch、路由器和投标 profile | Windows 路径、CRLF、权限和重启持久化测试全绿 |
| Office/Univer | Word、Excel、PPT 预览编辑保存 | `dsh-univer-office` 0.2.9 仍纳入运行时与安装包校验 |
| 安装与发布 | 安装结束默认勾选启动；多平台资产工作流 | Windows 安装体验不回退；3.3.5/3.3.6 历史资产不被替换 |

## 旧结构到 alpha.1 的迁移映射

| 旧补丁区域 | alpha.1 结构 | 处理原则 |
| --- | --- | --- |
| `packages/host/apiproxy`（14 个路径已移除） | `packages/api/gateway`、`session-controller`、`settings-controller`、`workspace-controller`、`remotes` | 按控制器职责重写，不恢复旧 ApiProxy |
| `packages/client/runtime`（7 个路径已移除） | `packages/api/session-controller/src/client`、`packages/client/connection` | 把会话事务和接续逻辑放到新 session contract/projection 上 |
| `packages/client/ui-conversation` | `ui-chat`、`ui-session`、`ui-approval`、`ui-input-trigger`、`ui-reference` | 按拆分后的 UI 包逐项移植，不重新制造单体 conversation 包 |
| 旧 `apps/cli/config/agent-presets/*` | `packages/preset/agent-presets` 与新 profile/bundle 入口 | 重写初始化和打包脚本中的 preset 路径 |
| `packages/llm/llm-pi-ai` 容量补丁 | alpha.1 LLM catalog / settings models | 先验证上游已有能力，再只补 Agent Pi 的来源标注与保守回退 |
| `compaction-basic` fallback 补丁 | alpha.1 `compaction-basic`、`command-compact`、图像感知压缩链 | 保留 72% 策略和跨供应商授权，不覆盖上游图像压缩改进 |
| 自建 Codex 子智能体桥 | 官方 `packages/subagent/subagent-codex` | 优先复用官方认证、模型选择和生命周期；桌面层只保留产品边界 |

## 执行阶段与门禁

1. **基线固定**：应用清单为 3.4.0，`DSH_PIN` 与嵌套 Git 指针均为 `cd5ef81481`，版本测试通过。
2. **上游裸基线**：不加载 Agent Pi 补丁，完成 alpha.1 安装、typecheck、核心测试和 web build；记录纯上游失败，不能把它们误判为移植回归。
3. **启动与 profile**：改写旧 preset/CLI 路径，桌面宿主能创建新 profile、启动 webserver、重启恢复；此阶段仍禁止发布。
4. **投标控制面**：先移植宿主接口、会话接续和审批收口，再运行 business-core、tender-host、tender-web 全量测试。
5. **Codex 与长上下文**：在官方 subagent-codex 和新 session controller 上恢复显式主对话路由、每会话事务、模型容量来源、72% 自动压缩与 DeepSeek 兜底。
6. **工作台能力**：恢复文件栏、知识库、web_fetch、AnySearch、Office/Univer 和 Windows 本地工具链。
7. **发布门禁**：DSH 全量测试/typecheck/build、Agent Pi 根测试、三组投标测试、Windows 安装包内容与启动复选框、多平台构建全部通过，才允许创建 `v3.4.0`。
