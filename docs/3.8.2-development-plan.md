# Agent Pi DSH 3.8.2 改造与验收方案

本版沿用当前开发分支，升级官方 DSH 0.2.1-alpha.2，并把已经原图验证的 CAD 修复整合进主对话、本次任务和专业工作台。保留完整 Univer Office、Windows 开箱即用 BIM 和九个可独立启停的工程插件。公开旧版安装包及标签保持其原始身份。

## 1. 内核与组件

- 官方内核固定到用户指定提交 `d743267388641bc76f17c45ce8b4c231aed1d32c`。使用该提交的锁文件和工具链，保持官方源码干净；产品兼容处理放在宿主、preset overlay 和插件适配层。
- 核对工具模式、工作目录、用户消息、会话持久化、聊天插槽及插件设置契约。升级后验证附件往返、任务状态、工作台跳转、专业深度开关和用户插件关闭状态。
- 更新有正式来源且能完成回归的 AnySearch、Univer Office、产品 Codex 执行器、PDF.js 和 Canvas。CAD 原生预览与独立 patched host 分别保留来源及完整对应源码，不用未经本项目验证的新版 npm WASM 覆盖。
- 全部应用及本版工程插件 manifest 为 3.8.2；旧工作流 ID 是持久化引用，继续保留以便已有项目恢复。

## 2. CAD 数据链路

`原 DWG → 已核验解码器 → 块/图层关系校核 → 流式 DXF → 来源版本缓存 → 磁盘索引与分页 → 工程观察 → 任务发现 → 工作台`

- 修复解压数据超过 256 MiB 时的位游标运算错误；在输出前检查真实块名和图层引用，拒绝已知失真模型。
- DXF 分块写盘，完整保存原始组码和内嵌二进制；大文件使用磁盘索引，几何投影按预算读取。
- 缓存绑定源图 SHA、完整 DXF SHA、代码与引擎签名、关系校核和警告。源图在转换或缓存核验期间变化时拒绝旧结果。
- OLE 单对象提取保留完整原始载荷；支持的位图返回 PNG。视觉识别与构件/料表识别分别进行，不把提取成功当作工程语义完整。

## 3. 专业联动

- 将转换警告、导出差异、未完成实例展开等信息送入标准工程问题记录，并投影到任务发现。完整细节可追溯，摘要优先显示影响目标的缺口。
- 分别保留结构清点、常规查询和各个内嵌对象的最新观察。查询分页更新同一记录，避免覆盖结构清点或制造重复发现。
- 工程面板显示原图及转换版本、解析/覆盖缺口，并通过现有文件预览打开内嵌 PNG。主对话可据此解释对算量目标的影响和下一步。
- 数量计算继续要求明确单位、几何尺寸、构件对应、专业规则及人工复核；未识别对象不得作为零工程量。

## 4. 验收

| 链路 | 检查 |
|---|---|
| 官方 DSH | 精确提交、源码干净、官方锁文件完整构建、构建回执与载荷一致 |
| CAD 原图 | 用户给定图纸哈希不变，8,414 条 INSERT 与独立原生 CAD 清点一致，1,111 条错误块名消除 |
| 内嵌内容 | 97 个载荷完整且逐对象可追溯，图像可打开；本图视觉内容为标识/联系方式 |
| 工程联动 | 实际注册工具进入账本、任务发现和面板，查询不覆盖 inventory，缺口不会因工具成功而消失 |
| 插件 | Office 完整分发及实际加载，AnySearch 参数/错误脱敏/来源适配，Codex 实际版本 |
| BIM | 独立复制已审核运行库后核验全部文件，实际 IFC 几何可读取 |
| 安装包 | 全新 staging、独立用户目录冷启动、版本/来源回执/校验和一致 |

原图仍有解析警告 68、57 个三维实体与 22 条样条导出差异，以及实例展开上限。本版明确呈现这些缺口，不声明全面算量完成。以上是验收目标，实际完成结果以本版验证记录为准。
