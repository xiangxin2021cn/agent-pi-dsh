# 3.7.3 内核升级

应用基线为已发布稳定版 3.7.2，沿用现有分支，不混入 3.7.0-RSI.1。DSH 固定到官方发行标签 `dsh-v0.1.7-rc.2`，提交 `477b4f420553e8a52c2fbccc464d7561b239c443`。用户提供的 `787b746b807df83776957875683b8853c862ca2c` 是版本号更新提交，发行标签位于其后的官方合并提交。

## 官方更新及本应用适用范围

本次按 rc.1 与 rc.2 标签间源码核对。共用 Web 和内核能力包括快捷键管理、对话中启用工具、定时任务与运行记录、归档筛选、模型切换等待提示、文档预览和审批本地化；修复写入锁残留、插件安装中断、工具输出截断和长对话请求失败。标准模式减少固定指令开销。定时任务与时间上下文保持官方默认关闭，普通对话不额外开启投标或知识库流程。

官方桌面产品还调整了首次引导、关闭窗口后继续运行、账号页面、Windows 升级界面等。这些依赖官方 desktop-host 与桌面通信接口，本应用仍采用现有 Electron 壳运行 DSH Web，不能仅因更新子模块就宣称这些桌面专属功能全部接入。桌面通信迁移不在本次范围内。

## 兼容要求

- 保留 3.7.2 的生产方专属 V4 消息来源、附件投递确认及显示层事务标记过滤，不改写历史消息日志。
- 延续官方四档工作步骤展示，不重新添加产品层强制隐藏样式。
- 保留完整 Univer 0.3.5、CAD 对应源码和运行文件、MPXJ、右侧文件栏、可选 Agent Teams、Codex、专业深度、手动模板及报告技能。
- 不整体替换原生提示词，不修改官方内核源码，不自动豁免插件版本检查。
- 跟随官方锁文件升级 LibreOffice Kit 至 0.1.1；Windows 打包继续验证原生引擎及安装链接，不以依赖安装命令成功代替包内检查。
- Univer 更新至 0.3.5，包含 Windows 重复备份修复；使用上游原生卡片、设置与侧栏适配，不再对本版本应用旧补丁。插件市场更新至 1.65.1，并保留本应用的受监管重启、Teams 管理及 IM/邮件兼容判断。
- 官方 rc.2 清理脚本未识别新加入的 `lib/desktop-keyboard-test-types` 输出目录。产品构建器执行临时副本，只增加这一固定目录的识别，保留官方边界校验；随后删除副本。官方受版本控制源码保持干净，构建收据明确记录此命令。

## 发布验证

发布前检查版本、内核 pin、官方兼容判断、真实 profile 启动、附件 V4 编码和恢复、PDF 加两图、文件栏注入与历史显示。使用隔离用户目录和合成文件，避免触碰真实会话。模拟模型仅验证附件传输与持久化，不能证明真实模型理解质量。

安装包需通过官方干净构建及收据校验、完整依赖检查、Univer 包内文件核对、CAD 源码与运行库核对，以及各平台 SHA256 检查。实际执行结果另行记录，不将本节的验证要求当作已经通过的结果。
