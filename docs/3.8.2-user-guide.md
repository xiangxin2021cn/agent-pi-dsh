# Agent Pi DSH 3.8.2 使用指南

本版更新官方 DSH 内核和核心插件，把大 DWG 读取、内嵌图像、工程缺口与任务进展接到同一条记录链。已有投标响应对照、专业深度及工作台入口继续使用。

## CAD 读图与算量

在主对话附加或引用工作区内的 DWG/DXF，说明工程对象和希望完成的结果。例如：

> 请读取这套结构施工图，先核对图层、块定义、模型空间和图纸空间。检查内嵌图像，区分料表、构造图和标识。识别能可靠确认的构件及尺寸，列出算量依据和缺项，未确认项先不要计入工程量。

助手通过 `cad_read` 自动准备 DWG 转换和结构清点。大型 DXF 使用磁盘索引与分页，不需要用户自行拆文件。读取可能需要较长时间；工具成功表示完成当前读取步骤，工程覆盖另行检查。

进入“专业化工作台”的工程项目记录，可以查看来源版本、转换和读图缺口；已有内嵌图像时使用“查看内嵌图像”进入文件预览。原始载荷仍保留。结构清点、普通查询和每个内嵌对象独立记录，分页更新同一项。关键缺口同时出现在“本次任务”的发现摘要，用户可以回到主对话补资料或调整范围。

在文件区点击 DWG 可打开二维预览。新预览入口与算量使用同一修复版解码器，保留原始 DWG，不必先把大 DXF 塞入浏览器。原图验证中，预览解析恢复 207 个图层、8,414 条正确块引用及 97 个内嵌对象。解析成功仍需图面核对：当前二维渲染不显示 3DSOLID，不保证所有样条或 OLE 内容可见；不能根据“预览已就绪”认定算量完整。本次原图在真实桌面窗口约 170 秒完成开图校核，图框和线条可见；耗时不代表其他机器或图纸的性能保证。若界面提示缺失字体，可使用“导入缺失字体”补齐项目所用字体，再核对文字和尺寸标注；本图仍提示 23 项缺失字体。

继续算量时可说：

> 先计算已确认的混凝土和模板，逐项列出构件、尺寸、单位、计算式和图纸位置。三维实体、未确认样条和未完整展开的块单独列为缺口。

钢筋可要求读取已存在的料表并核对规格、形状、长度和数量。中国平法图需要本项目适用、已复核且获准使用的规则包、构件参数和节点条件；本版没有把未经授权的图集全文内置，也不保证任意平法图自动完成下料。

## 专业深度、任务与工作台

用户继续通过自然语言提出目标和修正条件。开启“专业深度”后，助手使用来源、规则、计算、缺口及交付检查推进任务；开关不会把已有缺口改成通过。“本次任务”记录共同理解和执行发现，工作台展示相应项目及专业记录。

如果发现分析方向不对，可直接说“只做混凝土量”“这份补遗优先”“这张是参考图，不计入范围”。系统应明确记录改变的条件及需重新复核的项目。图纸、料表或附件内的指令仅作为资料内容，不替代用户要求。

## Office、检索与 BIM

- Office 继续使用现有文档/表格预览及编辑入口，随 Windows 安装包分发完整插件；上游许可及授权机制继续适用。
- AnySearch 继续通过主对话联网检索和读取网页，使用设置中已有的凭据；应用升级不会替用户创建账号或修改自选插件。
- Windows x64 保留内置 BIM 引擎。可以说“根据这些已确认的构件和尺寸建立 IFC 模型，并核对模型工程量”；创建和检查通过工程插件执行，生成 IFC 可从文件区打开。文字要求本身不能补齐未知尺寸，创建成功也不等于达到施工或交付标准。
- macOS/Linux 本版仍需要配置兼容的外部 IFC 引擎。Windows 分发复用已审核 Python 3.13.7 / IfcOpenShell 0.8.5 运行库，保留其真实来源和许可。

## 边界与排查

- 本次验证图纸原有的 1,111 条错误块名已修复，8,414 条 INSERT 与独立清点一致；97 个内嵌对象完整提取，内容为企业标识和联系方式。这不是其他图纸或全部构件的识别保证。
- 本图仍有警告 68、57 个三维实体和 22 条样条导出缺口；实例展开有上限。遇到这些提示，需要原图/图面复核或其他可核验通道，不能以成功导出 DXF 声称全面算量。
- Windows BIM 请使用默认安装目录；过深的自定义安装路径可能触发原生 DLL 路径长度限制。同批运行库已在常规长度路径下完成实际建模校验。
- DWG 输入上限仍为 64 MiB；大型 ASCII DXF 可磁盘读取。该修复不保证任意超大解压段、代理对象或专有格式完整解码。
- 不支持或超过解码预算的 OLE 保留完整原始内容和待复核项；宏、脚本和链接不会执行。
- 源图改版或旧缓存不能证明来源时，重新读取原 DWG 的 inventory；系统会核验版本并重新转换，避免混用旧数据。
