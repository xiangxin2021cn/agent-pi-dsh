## alpha.4 迁移要点

- 插件兼容预检优先采用 `engines.dsh`，否则检查 DSH peers。产品使用精确已审阅版本，不自动豁免用户第三方插件；旧插件配置和凭证保留。
- Goal 继续调用官方 round driver，使正在运行的子智能体先完成，再决定续轮；本次任务控制通过主对话的真实用户消息回写，不能仅改界面状态就宣称执行已暂停或完成。
- 子智能体接口改为独立 `agentPreset`，移除旧 `toolFilter`、`persona` 启动字段。产品桥和测试按当前合同验证。
- Chat 将用户图片与输出图片插槽分开，附件、发现和任务卡需要按新版 owner props 验证；版本升级不能只通过配置导出来认定真实 UI 激活成功。
- 保留生产 peer link 修复、旧 profile 覆盖迁移和 Mac 12 launcher overlay；不改用户自有第三方插件的版本。

## 工程引擎的取舍

MLightCAD 当前最新为数据模型 1.15.10 / 转换器 3.15.10，LibreDWG Web 为 0.8.0。本版继续保留数据模型 1.14.3 / 转换器 3.14.3 及经原项目大图验证的 `0.7.10+bit-cursor-fix.1` host decoder。普通 npm 更新会覆盖已修复的大图位游标、流式 DXF、磁盘索引、块引用和内嵌对象通道，因此需要独立原图回归和对应源重建后才能替换。

MPXJ 保持 16.10.0；Super Injector 保持 0.3.5；Router Standard 保持 `b39112dce54b90e67b50b166c2773861d7945d1f`。已核实这些现有来源仍适用。Windows BIM 保留已审计、具备完整对应源材料的现有 IfcOpenShell 分发；不以新 wheel 覆盖可追溯引擎。Mac/Linux 仍需配置对应平台的外部 BIM 引擎。

## 验证边界

插件、原生加载、协议握手、确定性模型替身和安装包身份检查分别记录；这些结果不能证明真实付费模型长程任务的最终质量。CAD 解码/保留内嵌载荷不等于全部图纸语义识别或全面算量。已有 Intel Monterey 安装包的验证结果属于 3.8.2；3.8.3 的跨平台产物必须另行构建与验收。
