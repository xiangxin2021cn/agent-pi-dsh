# Agent Pi DSH 3.8.3 改造与验收方案

## 范围与假设

沿用现有升级分支和插件架构。核心目标是让主对话理解目标、执行和反馈，让“本次任务”记录共同理解并提供有效操作；不要求普通任务先创建专业项目。此次不重做 CAD 算量引擎、不扩展新的行业流程，也不把按钮确认理解视作成果验收。

保留完整 Univer Office、九个工程插件、现有 CAD 大图转换修复、Windows 内置 BIM，以及 Intel Monterey 独立兼容构建策略。安装包从新源码和锁文件构建。官网默认下载在对应公开资源验证后再切换。

## 1. 内核和组件

- DSH 固定到官方 0.2.1-alpha.4 / f2235d6c023a81d86b202db5e472167ad2307ddb，使用官方锁文件完整构建，维护源码干净和构建回执。
- 核查新版 agentPreset、会话创建、聊天附件插槽、goal driver 和插件版本契约。产品适配放在插件与包装层。
- 检查官方组件来源，仅更新已完成兼容验证的组件；保留 CAD 已核验 decoder 及对应源码，不用新版本号替代原图回归。
- 同步产品 manifest 为 3.8.3；历史项目工作流 ID 与用户停用插件状态保留。

## 2. 一条任务操作链

任务页 / 对话摘要 → professional-task user_action → 版本与操作编号校验 → 持久任务状态 / 原始用户要求 → 当前 DSH 或 Codex 主执行器 → 真实回执 → 所有界面刷新。

| 操作 | 实际行为 | 验收边界 |
|---|---|---|
| 确认当前理解 | 确认已有目标与条件来源 | 不批准工作台阶段，不验收成果 |
| 补充或调整要求 | 记录用户原文、消息身份和绑定项目要求；运行中 steer，空闲 followup | 最新用户要求进入执行上下文；重复操作不重复派发 |
| 重新规划 | 采用用户本次调整并要求主执行器重排受影响工作 | 保留有效依据和成果，不重置阶段门禁 |
| 暂停执行 | 暂停已有 goal / 项目自动接续，取消父子执行；原生 Codex 等待停止确认 | 重启仍显示暂停；失败不能显示已暂停成功 |
| 继续任务 | 读取实际任务，复用工作台 resume / dispatch 或普通任务原生消息 | 不越过预算、审批和来源缺口 |
| 处理发现 | 将用户意见与稳定 findingId 一起交给主执行器 | 不因提交意见自动将发现标为已解决 |
| 核验成果 | 核验已登记实际成果与覆盖缺口，反馈主对话 | 不自动授予客户验收或签名 |

所有操作限制在主对话及对应工作区。revision 防止基于旧任务误改；operationId 防止双击或重放启动第二个执行者。工具记录和附件内容不能变成用户指令。

## 3. 原生 Codex 与专业工作台

原生 Codex 运行在 Electron 主进程。宿主准备命令，受信桌面 IPC 领取命令并调用原生 turn/start、turn/steer 或 turn/interrupt，随后回写收据。客户端不能通过任意成功 ack 伪造执行。准备命令在重启后失效时明确要求重新操作，不自行重复启动任务。

阶段审批继续使用带 approvalFingerprint 的真实人工门。批准后重新读取任务版本并继续执行；若续跑被阻止，分别显示“阶段已批准”和续跑失败原因，允许用户核对后重试。项目总目标、当前阶段目标分别展示。

原生问答和权限审批保留原提供者处理。任务页提供返回原生问答入口，不伪造答案或权限。

## 4. 界面与状态

- 任务概览和对话状态卡使用同一组任务操作；调整采用自然语言输入。
- 发现可查看依据、提交处理意见，并保留目标影响与未解决状态。
- 统一 DSH、Codex、任务快照与项目变化订阅；旧版本不能覆盖新回执；加载和执行失败可见。
- 专业深度设置同步读取共同任务状态，不单独维护一份旧需求。
- 页面刷新恢复任务控制、最近操作及依据；不依赖隐藏的编辑草稿执行。

## 5. 验证

1. 普通未绑定项目任务：调整 → 主执行器收到原文 → 对话与任务页同版本；暂停 / 继续真实生效。
2. 运行中调整：只 steer 既有执行者；旧 revision / 重复 operationId / 子对话控制被拒绝。
3. 项目任务：确认阶段成果 → 批准 → 续跑；预算耗尽和门禁阻止仍有效。
4. 发现意见不自动 resolved；核验不自动 accepted；原生问答不被旁路回答。
5. 原生 Codex 协议：start、steer、stop 确认、失败回执、快速完成、同操作重放及工作区身份。
6. 真实 Electron 产品页桌面与窄屏操作，刷新恢复、无白屏 / 控制台错误；Office 实际加载，工程回归。
7. 全新 Windows 安装载荷：版本、DSH 提交 / 构建回执、组件清单与 SHA-256 一致。

以上为实施和验收要求，实际测试与安装包证据记录在本版验证文档，不将测试替身视为真实长程模型效果证明。
