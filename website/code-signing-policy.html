Code signing policy

本页说明 Agent Pi DSH 安装包的签名与完整性校验政策。

  • 3.5.1 参赛演示安装包当前未签名，Windows SmartScreen 可能提示风险。
  • 每个定向交付构件同时提供 SHA256 校验值，用户应在安装前核对。
  • 后续正式签名构件只通过受控发布流水线生成，签名密钥由签名服务托管，项目维护者不直接接触私钥。
  • 签名状态与 SHA256 以随安装包提供的交付说明为准。

如有签名相关问题，请通过参赛测试通知中的项目联系人反馈。

This page states the installer signing and integrity policy of Agent Pi DSH.

  • The 3.5.1 competition installer is currently unsigned, so Windows SmartScreen may display a warning.
  • Every directly supplied artifact includes a SHA256 value that should be verified before installation.
  • Future signed artifacts will be produced only through a controlled release pipeline; signing keys remain with the signing service and are not directly accessible to maintainers.
  • The delivery note supplied with each installer is authoritative for signing status and SHA256.

For signing questions, use the project contact included with the competition test notice.
