Code signing policy

本页说明 Agent Pi DSH 的代码签名政策，对应开源项目 xiangxin2021cn/agent-pi-dsh。

  • Free code signing provided by SignPath.io, certificate by SignPath Foundation.
  • 代码签名只用于正式发布的安装包与二进制文件。
  • 被签名的构件必须来自公开仓库的 CI 发布流水线（GitHub Actions），不接受任何本地上传的构件。
  • 签名密钥由 SignPath 托管，项目维护者无法直接访问私钥。
  • 发布角色：仅仓库所有者（@xiangxin2021cn）可触发发布流水线。
  • 每个发布构件同时提供 SHA256 校验文件，用户可自行核对。

如有签名相关问题，请在 GitHub Issues 反馈。

This page states the code signing policy of Agent Pi DSH, for the open-source project xiangxin2021cn/agent-pi-dsh.

  • Free code signing provided by SignPath.io, certificate by SignPath Foundation.
  • Code signing is used exclusively for installers and binaries of official releases.
  • Signed artifacts must be built by the CI release pipeline (GitHub Actions) from the public repository; locally uploaded artifacts are never signed.
  • Signing keys are held by SignPath; project maintainers have no direct access to private keys.
  • Release role: only the repository owner (@xiangxin2021cn) may trigger the release pipeline.
  • Every release artifact ships with a SHA256 checksum file for user verification.

For signing-related questions, please open an issue on GitHub Issues.
