隐私政策

Privacy policy

本政策适用于 www.agent-pi.app 网站（以下简称「本站」）。最后更新：2026-08-30。

本站收集什么

  • 不收集任何个人信息。本站没有账号系统、没有表单、没有分析脚本、没有广告、没有 Cookie。
  • 你的语言与主题偏好仅保存在你自己浏览器的 localStorage 里，不会发送到任何服务器。
  • 首页和下载文档会从 GitHub 的公开 Latest Release API 读取当前版本与安装包链接；GitHub 会按其隐私政策接收常规请求信息（如 IP、User-Agent）。接口不可用时，页面使用本站随静态版本发布的已验证链接。
  • 字体文件加载自 Google Fonts，失败时自动回退到系统字体，不影响使用。

托管与日志

本站由 Cloudflare Pages 托管。Cloudflare 作为托管方会按自身隐私政策记录常规的服务器日志（IP、User-Agent 等），本站无法访问这些日志。

安装包交付

下载按钮会打开项目的 GitHub Releases 资产。Windows 用户安装前应核对页面显示的 SHA256；其他平台请以对应 Release 资产信息为准。

桌面软件

Agent Pi DSH 桌面端的数据（项目、会话、知识库）保存在你的本机（%APPDATA%\agent-pi-dsh-desktop），不会上传给我们。模型对话内容只发往你自己配置的模型服务商（如 DeepSeek）；仅当你主动使用 Codex 子智能体时，独立任务说明及其引用内容会通过 ChatGPT/Codex 发送给 OpenAI。

联系

隐私相关问题请通过参赛测试通知中的项目联系人反馈。

This policy applies to the website www.agent-pi.app. Last updated: 2026-08-30.

What this site collects

  • No personal data. This site has no accounts, no forms, no analytics, no ads, and no cookies.
  • Your language and theme preferences live only in your own browser's localStorage and are never sent anywhere.
  • The home page and download documentation query GitHub's public Latest Release API for the current version and installer links. GitHub receives ordinary request metadata (such as IP and User-Agent) under its own privacy policy. If the API is unavailable, the page keeps the verified links shipped with the static site.
  • Fonts load from Google Fonts, with automatic fallback to system fonts if unavailable.

Hosting & logs

The site is hosted on Cloudflare Pages. Cloudflare, as the hosting provider, keeps routine server logs (IP, User-Agent, etc.) under its own privacy policy; we have no access to those logs.

Installer delivery

Download buttons open the project's GitHub Releases assets. Windows users should verify the SHA256 shown on the page; for other platforms, refer to the corresponding Release asset information.

The desktop app

Agent Pi DSH desktop data (projects, sessions, knowledge base) stays on your machine (%APPDATA%\agent-pi-dsh-desktop) and is never uploaded to us. Chat content goes only to the model provider you configure (e.g. DeepSeek); only when you invoke the Codex subagent are its self-contained brief and referenced content sent to OpenAI through ChatGPT/Codex.

Contact

For privacy questions, use the project contact included with the competition test notice.
