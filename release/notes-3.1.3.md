# Agent π 3.1.3 — 冷子代理历史不再扫全部兄弟

本版在上一轮 3.1.3（审批回执、上传隔离、文件栏、主历史不复制、8GB 堆、崩溃拉起）之上，再修投标父会话打开第二个子代理后，主对话、切会话、发消息全部发黏的问题。

## 冷子代理历史把宿主事件循环堵住

第一个仍在运行的子代理走内存快路径，能打开。第二个已经结束的子代理走 `subagent.history` 时，仍先对父会话下全部兄弟做 `listChildren`（并发 inspect 冷日志）。一百多个清单工人会把宿主事件循环堵住超过浏览器 30 秒 unary。

堵住之后：

- 第二个子代理停在「载入历史...」
- 切到只有几个子代理的无关对话也停在「载入历史...」
- 主对话发出的字没有本地假气泡，要等 `session.prompt` 和 SSE；循环一堵就「发出去了但不显示」
- 模型首 token、Deep diving 计时被同一条循环拖慢，看起来比原生 DSH web 钝
- 堆继续涨到约 3.7GB 后 `dsh web` 以 134 退出

现改为只 inspect 这一个孩子的 header / origin / 身份，不再扫兄弟。`subagent.list` 和续写 prompt 仍走目录。

## 仍保留的上一轮热修

- 主对话 `session.history` 不再整份复制内存日志
- 桌面把 `dsh web` 堆提到 8GB，异常退出后自动拉起
- 右侧「资源文件」读当前会话自己的工作区
- 回形针上传按 `sessionId` 分桶
- 审批回执本轮立刻接受，失败可重试
- 3.1.2 的热子代理历史跳过目录

167 个进程内子代理本身仍占堆；本版去掉打开冷孩子时的全量兄弟扫描。
