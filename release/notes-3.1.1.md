# Agent π 3.1.1 — 视觉能力与插件生态

3.1.0 完成「换心脏」（内核迁移至 DeepSeek Harness）之后，3.1.1 聚焦三件事：给文本模型装上眼睛、打开社区插件生态、把安装体验拉回正轨。

## 视觉路由 dsh-vision-router（文本模型的眼睛）

- **对话直接贴图**：官方 DeepSeek 本身不能看图；本版以隐身模式接管 DeepSeek 路由——模型选择器保持原样，任意模型收到图片时自动路由到视觉模型解析，再把结果交回主模型，无需切换任何开关或模型组。
- **11 个像素级工具**：`vision_describe`（看图问答）、`vision_ocr`（精确取字）、`vision_crop`（局部放大）、`vision_ground`（目标定位）等，Agent 在任务中可自主调用。
- **扫描版 PDF 场景打通**：图纸、扫描页先导出为图片，再由 vision 工具解析——投标文件里的工程图、签章页不再是盲区。
- **附件上限放宽**：图片附件上限提升至 20MB。
- **插件可独立更新**：预装版本 1.4.4；设置卡里的「一键更新」现在能把预装副本升级为 npm 正式安装（此前会误报「Already up to date」），更新在重启后保留，应用升级自带更新副本时才会接管。
- 旧的自研「视觉桥」方案（设置里的视觉模型开关、输入框图片按钮）整体退役，由 vision-router 统一接管，路径更短、行为更稳定。

## 插件市场 dshmarket（逛一逛，点一下，装好）

- 设置 → **插件市场**：浏览 1000+ 社区为 DeepSeek Harness 打造的插件，发现 / 主题 / 已安装 / 备份与恢复四个标签页，支持搜索。
- 一键安装、一键卸载，装完即热加载；本应用预装的插件（视觉路由、投标工作台等）也在「已安装」里统一可见。
- 市场自身走独立更新通道，插件目录每天都在增长。

## 安装与更新体验

- **安装大提速**：回归 3.0.0 验证过的 7z 整包解压方案（electron-builder NSIS 逐文件解压 6 万个文件是 3.1.0 安装 10 分钟+ 的元凶）；同时从载荷中剔除约 1.8 万个编译期文件（类型声明、sourcemap），安装包更小、解压更快。
- **应用内检查更新**：菜单「应用 → 检查更新」手动检查；启动后也会静默检查一次，发现新版本提示下载，下载完成后一键安装。
- **关闭窗口可选最小化到托盘**：点击关闭按钮时可选「最小化到托盘（后台常驻）」或「直接退出」，支持记住选择；托盘常驻时后端保持运行，从托盘图标一键回来，免去二次启动等待。菜单「应用 → 关闭窗口时」可随时改回。

## 修复

- 修复 Windows 11 上浏览框「导出 PDF」导致整个应用崩溃：优先调用本机 Chrome / Edge 排版，找不到浏览器时再走收紧后的 Electron 回退；长代码块不再用会卡死排版器的强制分页。
- 修复设置面板中「插件」区块（super-injector 旧协议渲染）导致的 React 崩溃：入口移除，注入管理由原生插件页 + 插件市场承接，宿主 API 不受影响。
- 修复 vision-router 依赖解析：其 `@deepseek-ai` 对等依赖现在直连内置 DSH 运行时，避免服务注册身份错位。
