# Agent Pi DSH 3.5.3 — 每会话附件事务正式版

3.5.3 收口主对话附件从选择、预处理、提交到 DSH 会话持久化的完整生命周期。DeepSeek Harness 内核保持 **`dsh-v0.1.2-alpha.3`**（`dd6322d604`），本版本未修改官方内核源码。

## 核心变化

- 普通附件与 Codex 附件统一使用每会话显式事务控制器，状态覆盖准备、提交、领取、持久成功、失败、取消和会话销毁。
- 隐藏附件上下文绑定唯一事务标识和用户消息；只有该消息真实进入会话后才清空附件，失败则恢复原草稿和附件以便重试。
- 多会话并发、同路径重新添加、准备期间修改草稿或附件，以及会话销毁均隔离处理，旧事务不能误清除新事务。
- `tender-host` 在消息领取后绑定交付消息，仅以匹配用户消息的持久化事件确认交付；步骤边界不作为成功 ACK，避免前端显示附件但模型仅收到路径文字。
- Windows 打包在构建前安装 `tender-host` 锁定依赖，确保 PDF 与文档处理依赖随安装包进入运行时。
- 官网首页新增十语言选择：简体中文、英语、西班牙语、法语、德语、日语、韩语、葡萄牙语、阿拉伯语和俄语；GitHub Latest Release 仍负责自动同步下载版本与三平台资源。

## 发布治理

- 发布线固定为：功能分支 → PR → `main` merge commit → `v3.5.3` 标签 → draft Release → 八项资源齐全 → Latest Release。
- Windows、本地运行时、macOS 与 Linux 资产均禁止覆盖；同版本不做资源替换。
- 内核未变更，应用版本因用户可见修复提升到 3.5.3。
