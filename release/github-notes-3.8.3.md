# Agent Pi DSH 3.8.3 — 任务交互闭环与官方内核升级

本版重点改造“本次任务”：主对话、任务概览和专业工作台共享目标、依据、发现及真实执行状态。修改要求会通知当前执行器；暂停、继续及阶段审批后续跑具有真实回执。

## 具体改动

- 对话目标卡和任务概览加入补充或调整要求、重新规划、暂停、继续和成果核验。输入自然语言即可，无需把任务逐项翻译成表单。
- 保存用户原文、消息身份和绑定项目要求；运行中使用当前执行器的 steer，空闲时提交后续回合。旧版本拒绝覆盖新任务，重复操作不重复启动。
- 发现卡可提交关联处理意见；提交不会自动消除发现、补写问题答案或授予客户验收。
- 阶段批准继续核对实际成果指纹，成功后自动提交续跑。批准与续跑失败分开显示，可重试继续而无需重复批准。
- 暂停保留已有成果，阻止自动接续并等待父子执行停止。停止未确认会明确显示，可重试；刷新和重启保留暂停记录。
- 原生 Codex 操作由受信桌面 IPC 领取宿主准备命令，通过真实 start / steer / interrupt 回写结果。工作台启动遵循当前执行器选择，Codex 运行时隔离旧 DSH 自动调度。
- 专业深度、对话状态卡和任务页统一订阅任务及项目变化，显示加载失败、最新要求和执行结果；旧快照不能覆盖新状态。
- 高级字段仍可编辑，“保存并调整执行”会先保存修正，再将实际修改字段送交执行器。

## 怎么使用

1. 主对话描述目的并提供资料，例如“先检查工期与资源，形成给项目经理使用的建议，未知条件列为缺口”。
2. 在对话目标卡或“本次任务 → 任务概览”点击“补充或调整要求”，说明需要改变什么，查看执行回执及后续反馈。
3. 需要中止时点击“暂停执行”；确认停止后使用“继续任务”。待答问题、阶段审批、预算或来源缺口会明确阻止越界续跑。
4. 对发现点击“补充或调整处理”，提供事实或决定；使用依据按钮核查原稿。
5. 有成果后使用核验操作检查实际文件。客户验收和签署仍独立确认。

详细操作和能力边界见本版使用指南；组件来源及迁移说明见核心组件更新记录。

## 安装及能力边界

Windows x64 本地交付为 Agent-Pi-DSH-3.8.3-x64.exe，附同名 .sha256 和 .build.json。升级前保存文件并退出应用，沿用默认安装目录。安装包未签名；本次 Windows 验收不代表 macOS/Linux 资源已完成构建。

原生 Codex 开始新工作需有效登录，停止不依赖登录有效期。问题和权限由原生问答处理；继续、确认理解及模型核验均不等于阶段审批或客户验收。

CAD 读取成功不代表图纸语义和算量完整；中国平法钢筋仍需适用且获准使用的规则及节点条件。Windows BIM 只对支持的已确认参数构件建模，不能从任意 CAD/PDF 一键生成完整 BIM；macOS/Linux 需配置外部 IFC 引擎。未更新已核验工程引擎的版本号，不代表删除已有能力。

确定性模型替身、原生协议、真实界面及载荷核验分别记录；它们不证明真实模型长程任务的所有专业判断质量。

暂停前已排队的输入会以原消息身份持久暂存，可在操作区展开核对。继续 DSH 时恢复到原会话和队列；暂停后的最新修正优先。原会话尚未加载、已归档或工作区变化时会明确阻止恢复。选择 Codex 继续会保留旧 DSH 队列，不额外唤醒 DSH。

主对话的真实新消息在持久入队时即同步到共同任务；取用、恢复或重复消息不会覆盖后来要求。执行器更新结构化理解和成果需要实际执行，登记及时不等于专业判断已完成。

工作台“继续推进”和“恢复事务”也通过同一条任务继续链；任务页暂停后可从工作台恢复。仍需先处理原生问题、实际阶段审批和预算限制。暂停事务只冻结项目自动接续；需要同时停止当前对话和子任务时使用“暂停执行”。

暂停中仍可人工调整要求、重新规划或核验成果；这些操作保持自动接续暂停，只有明确点击继续才恢复自动执行。
