# Agent Pi DSH 3.8.0

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.8.0","kernel":{"releaseTag":"dsh-v0.2.1-alpha.1","commit":"ec48669f48ac81bac353fc646e7cf9c57241242f"}} -->

本版新增九个工程插件，将图纸来源、构件、规则、计算、缺项和成果关联到同一工程账本，并与主对话、本次任务和专业化工作台联动。沿用官方 DSH 0.2.1-alpha.1、原有南非投标流程、Codex 主执行及完整 Univer Office 0.3.6。

**第一次使用请看下面的“BIM 三步上手”和“九个插件怎么用”，更完整的对话示例、界面说明和排查方法见 [3.8.0 使用指南](https://github.com/xiangxin2021cn/agent-pi-dsh/blob/main/docs/3.8.0-user-guide.md)。**

## 工程行业能力

- **CAD/PDF**：DWG/DXF 实体、嵌套块、图层与布局清点；PDF 页目录、带坐标文本、局部高清渲染和分块。明确保留外参、未知实体、未读范围与展开预算缺口。
- **钢筋与平法**：区分料表与平法入口；规则按项目检查内容指纹、采用固定版本；几何、计量、加工和采购口径分别保存。未知锚固、搭接、构造及抗震条件不能自动补齐。
- **道路、市政及土建**：明确断面积分、管沟折线、结构层面积与厚度、矩形构件及计数；区分完整量、已知部分和未知项，并与独立范围目录比对。
- **IFC/BIM**：模型清点、构件预览、原生数量与几何量对照，以及明确参数下的矩形梁、板和代理构件生成。Windows x64 内置官方 CPython 3.13.7 和经来源、依赖及许可材料核验的 conda-forge IfcOpenShell 0.8.5，保留 CGAL 与 OCCT 几何能力。macOS 和 Linux 仍需配置兼容的外部 IFC 引擎。
- **中国招投标**：制度、地区、行业和时效适用建议，要求—证据—响应矩阵，原始 BOQ 基线及复算差异，独立五阶段工作台。
- **计算书与 Office**：导出真实 XLSX、CSV、HTML 和原始 JSON，关联任务草稿成果；源文件或采用依据变化后，受影响计算与交付转为待复核，历史文件保留。

## BIM 三步上手

**可以直接在主对话中提出“创建 BIM 模型”或“分析这个 IFC”。** Windows x64 的“开箱即用”指已内置 Python / IfcOpenShell，无需用户另装引擎；主对话智能体根据请求调用真实工具。当前没有独立“新建 BIM”按钮，也不是出现“BIM”关键词就自动建模。创建模型仍需明确构件、尺寸、单位、位置和新文件名。

1. **先检查引擎。** 在有工作目录的会话中发送：“请实际检查当前 BIM 引擎，返回是否可用、实际 Python 路径和 IfcOpenShell 版本，暂不创建模型。”预期调用 `bim_engine_health` 并返回检测结果。
2. **创建并回读。** 复制下面的演示请求，要求智能体生成文件后继续登记来源、核查并预览。
3. **查看结果。** 在主对话查看文件路径和工具结果；打开“本次任务 → 任务概览”，或已绑定会话的项目工作台，在“工程数据与计算”中查看记录。预览返回真实网格后，才会出现可旋转、缩放和选择构件的“IFC 几何预览”。

> 请用 BIM 工具创建演示用 IFC4 模型，项目名“BIM 入门演示”。只建矩形梁 B1：局部 X、Y、Z 尺寸分别为 6、0.3、0.5 米，最小角点在工程坐标 (0,0,0) 米，绕 Z 轴旋转 0 度。保存为当前工作目录内的新文件 bim-demo-01.ifc；若重名请使用新编号。生成后登记为生成模型来源，回读核对尺寸和位置，再生成三维预览与几何体积结果。请返回真实文件路径及待复核项。

这个无开口演示体的几何体积应为 **0.9 m³**。生成 IFC、登记来源、回读、预览和算量是不同操作，需要智能体继续调用；生成文件不会自动完成后续步骤。

分析已有模型可以这样说：

> 请分析当前工作目录中的项目.ifc：先清点单位、空间层级和构件类型，再分批查询梁、板。先处理前 10 个梁，展示真实几何预览，并分别列出原生数量、几何净量、毛量与开口扣除量；失败和未处理构件单列，有下一页时明确提示。

**BIM 边界：** 当前读取本地 `.ifc` STEP；生成限明确参数的矩形梁、板和通用代理构件（`IfcBeam`、`IfcSlab`、`IfcBuildingElementProxy`），输出新 IFC4。不是完整 BIM 编辑器，不直接创建钢筋节点、完整道路地形或任意复杂构件，也不支持 CAD/PDF 一键完整转 BIM。来源文件和输出需在当前工作目录，禁止覆盖已有成果。单文件最大 256 MiB，查询每批最多 100 个构件，几何/预览每批最多 20 个，新建每次最多 200 个；复杂模型需分批处理。macOS/Linux 仍需配置兼容外部引擎。

## 九个插件怎么用

| 插件 | 对话中可提出的任务 | 当前能力边界 |
| --- | --- | --- |
| 工程宿主 | “登记资料版本、构件范围、采用规则和缺口，沿用同一工程记录。” | 管理共同状态和来源关系，不自动证明全图完整 |
| CAD | “先清点 DWG/DXF 的图层、布局、块、尺寸、文字和外参，再读取指定范围。” | 转换与结构化读取不等于专业对象全部识别；特殊对象、外参和展开限制保留缺口 |
| PDF | “列页目录和坐标文字，对指定详图分块高清查看，记录未读范围。” | 没有自动 OCR 或全图钢筋识别；扫描页需视觉核查 |
| 钢筋与平法 | “先区分料表和平法，确定适用规则与构造条件，再逐组核算。” | 不是完整 G101 自动识图系统；需项目适用规则和结构化输入，不臆造锚固、搭接、弯折及抗震参数 |
| 道路 | “按桩号和横断面数据计算分段土方，列出缺失断面和未覆盖区间。” | 已支持的断面几何计算，不自动生成路线、地形或合同支付量 |
| 土建市政 | “核查管沟折线长度、面积×厚度、矩形构件和计数，完整量与已知部分分列。” | 限已实现的明确几何；复杂曲线、洞口和缺失尺寸保留未知，PDF 比例标定不等于自动量取 |
| BIM/IFC | “检查引擎，读取 IFC 并预览。”或使用上面的参数建模示例 | 支持范围与批次限制见“BIM 三步上手” |
| 中国招投标 | “按地区、行业和制度整理要求—证据—响应矩阵，比较原始 BOQ 与复算量。” | 基础规则来源有限，不覆盖全国地方规则；不自动判定资格，不做 CA 签章或交易平台递交 |
| 工程交付 | “导出 Excel 和计算书，保留来源、算式、未知项、规则版本与待复核状态。” | 输出 XLSX、CSV、HTML、JSON 并登记草稿；不自动验收，可继续使用 Office/Univer 处理表格 |

**减少算量漏项的推荐顺序：** 先明确目的与范围 → 对照图纸目录、构件表或原始 BOQ 建立独立检查目录 → 逐项读取 → 确认单位、比例及规则 → 分范围计算并列缺口 → 检查覆盖后导出。中国平法需要有合法使用权的适用规则及项目条件；上传图集 PDF 本身不会自动变成完整规则引擎。几何量、合同计量、加工量和采购量分别保存。

## 入口、开关和联动说明

- **主对话**是操作入口，普通会话也能调用已加载的工程工具。默认加载插件不等于上传文件后自动完成全套分析。
- **专业化工作台**提供“工程图纸与算量”和“中国招投标与响应复核”两个流程；选择流程后，可“升级当前工作／将当前工作升级”或“新建项目”，也可继续已有项目。资料可通过主对话提供，或在工作台“添加资料 → 保存登记”，再进入阶段会话推进。创建项目本身不等于开始执行，已有项目也不会自动改成新流程。
- **专业深度**控制检查与引导要求，不是 BIM 引擎或九插件的启用开关。关闭后，基础来源、单位、重复项和未知条件检查仍保留。
- **工程面板**在“本次任务”和绑定项目工作台中展示，空项目无对象、无运行记录时隐藏；仅上传附件、仅登记来源或独立健康检查可能仍不显示。已有记录约每 5 秒刷新，也可点“刷新工程记录”。只有预览操作返回网格时才有三维视图，“查看 IFC 文件”不会自动触发预览。
- **插件管理**从侧栏“插件 → 已安装”进入组合包详情，可管理组合包或组件开关。工程宿主与依赖插件需要正常加载。另一个“设置 → 插件 → 插件列表”是只读清单，不是开关页；用户此前卸载的插件不会被启动过程强制恢复。
- **变更与复核**：来源或参数改变后，相关结果转为待复核/待重算，需在对话中继续要求复算和重新导出；不会自动把旧结果算成新结果。历史文件保留，查看时确认同一会话或绑定项目。计算完成不等于专业审核、客户验收或加工批准。

完整步骤、失败排查和各项预算见 [使用指南](https://github.com/xiangxin2021cn/agent-pi-dsh/blob/main/docs/3.8.0-user-guide.md)；实现及专项证据见[行业平台说明](https://github.com/xiangxin2021cn/agent-pi-dsh/blob/v3.8.0/docs/3.8.0-engineering-platform.md)。

## 构建与验证

候选载荷通过工程回归 164 项、worker 集成 6 项、复杂几何旧版与新版引擎对照 9 项，以及发布相关回归 19 项。已验证九插件注册、主执行工具和独立 Office 加载；内置 Python 与七个非 IFC 依赖在隔离环境中导入，NumPy 线性代数及 Shapely 几何运算通过。固定官方归档重新装配的 1,206 个基础运行库文件逐一哈希一致；此项不表示已从源码重编译得到相同的上游二进制。

正式 Windows 安装包已核验内嵌载荷与构建回执一致，并在隔离解包目录验证九插件、内置 BIM、PDF/CAD 运行库、独立 Office 和真实应用冷启动，页面与控制台错误为 0。macOS/Linux 构建成功，全部 17 项发布资产已核对校验值。跨平台包材补齐 Codex 主执行模块，并检查桌面主入口的本地静态依赖闭包。这些检查不等同于实际 NSIS 安装向导、升级及卸载验证，也不证明任意实图识别和算量无漏项。

应用版本统一为 **3.8.0**，此前误写的 5.8.0 未公开发布。已有历史计算保留真实来源版本，不批量改写结果。Windows 安装包未签名。
