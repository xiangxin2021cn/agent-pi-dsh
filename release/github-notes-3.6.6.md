# Agent Pi DSH 3.6.6

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.6.6","kernel":{"releaseTag":"dsh-v0.1.5-rc.2","commit":"59f2e3be330e37bc2ab91c92da4a081bc3281988"}} -->

升级至官方 DSH `dsh-v0.1.5-rc.2`，保持官方内核源码干净，产品适配位于启动配置和扩展。

- 设置 → Codex 智能体中增加 Agent Teams 开关，默认关闭，保存后重启生效。开启后使用官方成员列表、消息、共享任务板和成员导航；模型仅在用户明确要求团队协作时创建成员。
- 开启 Teams 时同时处理全局与预设中的同名成员控制工具，避免重复注册。Codex 执行继续独立使用；官方 Codex provider 尚无 Teams 所需的可续跑成员接口。
- 打包沿用完整离线运行时，参考官方依赖图验证检查必需依赖及可用的可选依赖；保留构建完整性凭据和原生模块检查。启动失败展示具体错误与日志入口，提供临时排除外部插件的恢复模式。
- 桌面仍使用现有 HTTP 通信适配。保留 Linux AppImage/deb 打包、资源文件栏、本地 CAD Worker/WASM、官方 `dsh-univer-office` 0.2.13 完整插件及原始许可和授权校验。
- 已验证并允许用户从市场升级到 Univer 0.2.14；重启后不会再因旧版本白名单被停用。安装包继续内置 0.2.13。
- 修复内置自动压缩模块被插件市场误判为“不兼容”：它由对话预设加载。禁止单独卸载该预设依赖，防止损坏对话启动。
- 保留官方 `deepseek-flash` 原生图片能力、普通对话按需引用知识库和投标流程、专业深度、精简过程、Codex 模型与思考等级选择。

CAD 对应源码沿用已验证的 `Agent-Pi-DSH-3.6.2-CAD-corresponding-source.tar.gz`，来源提交 `1aef6820ebc450125788158a4b2d1706115cdd10`。
项目及发行物采用 `GPL-3.0-only`，第三方组件保留原始条款。正式 SHA256 以同一 Release 中的 `.sha256` 资产为准。
