# 3.6.5 文件浏览功能取舍

结论：保留 Agent Pi 资源文件栏作为唯一文件管理入口，停用官方 `ui-sidebar-files`；保留官方文档预览、workspace-files 服务、原生附件和交付卡片。通过产品 profile overlay 配置，不修改 DSH 内核源码。

比较基于官方 DSH `1ef9c1fa9afbea78c5537bfc8b6d1c27d598798e`（0.1.5-rc.1）。

| 能力 | 官方文件树/预览 | Agent Pi 资源文件栏 |
| --- | --- | --- |
| 当前工作目录文件 | 可以逐级浏览，目录条目有上限及截断提示 | 可以逐级浏览，过滤部分隐藏和内部目录 |
| 已落盘过程文件 | 在工作目录中即可查看，不要求先正式交付 | 可从工作区部分查看普通过程文件；并非显示所有内部缓存 |
| Agent Pi Outputs | 可作为普通目录展开 | 单列正式工作成果，并保留产品已有成果归集逻辑 |
| 上传资料、关联项目目录 | 主要按当前会话工作目录浏览 | 对上传资料、工作区及关联项目目录提供产品分组 |
| 文本/Markdown/代码/图片/PDF/HTML | 原生预览，支持标签和部分格式的行定位 | 保留已有预览；原生交付卡片仍可调用官方文档预览 |
| Office/CAD | 官方文件树本身不提供我们的完整 Office/CAD 工作流，可通过扩展接入 | 已有 Univer 编辑保存及 CAD 预览集成 |
| 工作操作 | 文件树主要为浏览、刷新、打开；workspace-files API 无写操作 | 上传、注入对话、导入知识库、导出正式产出及资源管理器定位等入口 |

不能以“官方看不到过程产物”为由删除它。取舍依据是产品已有工作操作与成果组织的完整性，而非文件是否已经生成。目录浏览以当前工作区为边界；未落盘内容或任意系统临时目录不等于自动进入文件树。官方单文件读取还受所配置文件系统权限控制，不能与目录列举范围混为一谈。

实现只停用重复文件树，保留官方预览。官方预览打开时协调右侧占位，关闭后恢复资源文件栏；Office/CAD 通过官方扩展注册路径进入现有完整预览器。
