# Agent Pi DSH 3.8.8 主线候选

本版将 3.8.7 的主线维护工作正式归入 3.8.8。投标专版的分支、安装标识、用户数据及升级通道保持独立。本地打包和验证不代表已经发布到 GitHub 或官网。

## 界面与插件维护

- 左侧折叠后常驻展开图标，右侧资源栏展开键位于窄栏顶部；窄屏专业工作台保留恢复入口及键盘焦点提示。
- 插件市场升级官方 1.73.9，主页面增加“检查市场更新”，发现新版本后复用既有更新和来源替换确认。只有明确的随包源可走在线更新，用户私有同名链接仍受保护。用户独立切换到社区原版时会明确提示本应用的市场界面适配不随之保留，并保留可验证的来源回退。网络失败不显示为“已是最新”。
- 针对 pnpm 10 与当前官方 pnpm 11 的依赖布局冲突，在 DSH 加载插件之前进行受控迁移：保留原依赖树和清单，只补齐已声明而锁文件缺失的本地链接，保持注册表解析冻结，禁止生命周期及 pnpm hooks，核验依赖入口；失败恢复原树并验证。中断或无法确认恢复时停止启动并保留备份，不能误建空 profile。
- 打包只排除仓库根开发文档，保留插件声明的介绍与预览图。新的 DSH receipt 对声明路径、文档存在和实际库存做检查；非法路径及链接逃逸仍拒绝。
- 本次维护文案覆盖语言选择器的十种语言，并修复切换语言后市场检查结果保留旧译文、阿语窄屏恢复键重叠及 Agent Teams 入口说明。侧栏十语四十态已验证；官方原生韩语/阿语及部分专业长文继续按原有规则回退英文，不宣称全应用或社区市场已全文翻译。

## 如何外派本地 Codex

主执行者仍是 DSH。移除的是产品自定义的 Codex 主执行器、设置入口和冗余 SDK，并未取消官方 `subagent_oar` 外派能力。DSH 可根据独立任务需要选择可用的 Codex 或 Claude；用户无需输入固定口令，也可以明确说：

> 把这个独立代码修复任务交给本地 Codex 执行；由 DSH 整理任务约束、检查实际修改并汇总结果。

本地 CLI 需已经安装并完成其原生登录。外派仅在实际插件、运行时和当前权限允许时执行；请求不会自动扩大权限。工作者不会自动继承主会话、知识库、范本和专业工具，DSH 需明确传递相关范围和约束，并根据真实返回和实际文件验收。无法调用或结果未知时应报告具体缺口，不能以普通文字声称已经外派。旧产品 Codex 历史保留只读。

## 长程任务与组件

“本次任务”默认折叠，保留原会话、项目、约束和人工决策。宿主跟踪持久派发意图、原生收据、来源版本及外派生命周期；不对未知副作用盲目重派。取消 API 金额上限，继续保留回合、已知 token、时间、无进展及权限边界；外部 CLI 未报告的 token 不记为零。

借鉴 Superagent 的恢复、授权及外循环思路，并非整体加载其研究原型；尚未实现通用 Source/Thread/SQLite Engine、跨进程租约或统一保存导出 Outbox。官方 OAR 是执行适配器，不是另一套主任务账本。沿用已审核的 DSH `ce7073d51254c26cd63b22a60835b8f948deb447`，保留完整 Univer、知识库、技能、模板 DNA、CAD/PDF、BIM 和项目计划运行时。
