# Agent Pi DSH 3.5.1 — 执行账本、阶段记忆与双态控制面板

3.5.1 解决投标主对话与专业工作台彼此不了解实际进度的问题。DSH 主智能体仍是唯一负责语义判断、计划和子智能体派活的“大脑”；控制面板负责呈现主智能体执行态与磁盘事实态，并把两者的差异精确送回当前会话。

DeepSeek Harness 继续固定在 **`dsh-v0.1.2-alpha.1`**（`cd5ef81481`），未修改官方内核源码。

## 主要变化

- 新增每会话持久化执行账本，记录目标、当前批次、计划、子任务分派、阻塞、下一动作和心跳。
- 控制面板同时显示“主智能体执行态”和“系统事实态”；面板不复制第二套计划器，也不再仅凭文件数量机械推进。
- “继续推进”只发送当前差异、未完成计划、磁盘变化和阻塞，避免反复向主对话注入整阶段长提示词。
- 人工决策门禁会停止自动推进；阶段提交成功时，同阶段执行账本同步收口。
- 延续 3.5.0 的不可变阶段记忆与 handoff：上一阶段成果作为下一阶段的磁盘基线，主对话只加载小型状态胶囊，精确事实按路径回读。
- 投标工作台保留 BOQ 溯源、结构化证据、价格冻结、合规检查和最终提交门禁。
