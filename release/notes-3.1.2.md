# Agent π 3.1.2 — 运行中子代理历史加载热修

3.1.1 上打开仍在运行的子代理（例如投标清单工人）时，对话页会卡在「载入历史…」，随后报 `signal timed out（internal）`。一次失败还会拖住宿主事件循环，主会话 SSE 一起停，看起来像整窗崩了。本版只修这件事，不改功能面。

## 修复

- **运行中子代理不再扫全部兄弟**：已挂接且 `origin=subagent` 的子会话直接读内存事件，不再先 `listChildren` 检查父会话下每一个冷子会话。冷子会话历史仍走目录。
- **超时可恢复**：超时文案说明子代理仍在后台运行；对话页提供「重新加载」，再点当前会话也会重试。后台任务不会因为看历史失败而中断。
- **桌面容错**：渲染进程崩溃后自动重载窗口（DSH 子进程不停）；主进程未捕获异常只记日志，不退出。
