# Agent Pi DSH 3.7.4 本地测试版

本版本供本地安装验证，尚未公开发布。DSH 内核继续采用官方 0.1.7-rc.2。

- 用户可在“专业化工作台 → 模块管理 → 自己新建工作台”中直接创建和修改工作台，配置阶段依赖、技能、知识库、人工审批及交付要求；对话辅助设计为可选功能。
- 工作台核心、知识库和投标、实施、投资模块按 DSH 原生插件管理，可独立启停。升级初始化保留用户主动卸载的决定。
- 新项目采用保存后的流程；既有项目保留原流程快照。模块删除后项目数据保留，停用模块禁止启动新的业务任务。
- 补充八种语言的工作台编辑文案，修复阿拉伯语侧栏遮挡和窄窗口编辑布局。全应用翻译尚未完成。
- 保留现有 Univer Office、CAD、MPP/P6 项目计划、文件栏、Codex 和团队能力。

建议先用一个测试工作目录验证：

1. 新建两阶段工作台，为第二阶段选择前置阶段，保存并重新打开。
2. 配置所需知识库和技能，创建测试项目，再修改工作台，确认原项目仍使用原流程。
3. 在插件管理中启停知识库/工作台，再恢复，确认入口与功能一起变化。
4. 检查常用 Office、图纸、项目计划预览和普通对话。

不自动安装或替换当前应用；请关闭正在运行的 Agent Pi DSH 后手动安装。完整回归和本地安装包检查结果随构建记录提供。
