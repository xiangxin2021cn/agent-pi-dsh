# Agent Pi DSH 3.7.9

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.7.9","kernel":{"releaseTag":"dsh-v0.2.1-alpha.1","commit":"ec48669f48ac81bac353fc646e7cf9c57241242f"}} -->

本版固定到 [DeepSeek Harness 官方 0.2.1-alpha.1](https://github.com/deepseek-ai/deepseek-harness/commit/ec48669f48ac81bac353fc646e7cf9c57241242f)，包含 pi-ai 0.87.1、Cordis 4.0.5-alpha.1、cosmokit 1.8.6-alpha.1、schemastery 3.18.5-alpha.1 及相关 Cordis 插件升级。官方内核源码保持不修改，使用官方锁文件与 pi-ai 流式工具参数补丁构建。原有专业工作台、任务引导、完整文件预览及 CAD DWG→DXF 导出继续保留。

Univer Office 升级到完整官方 0.3.6 插件，dshmarket 升级到 1.66.8。在审查实际接口变化后，产品适配仅扩展到本次核验的精确 DSH、Cordis 和 schemastery 预发行版本；现有会话持久化格式没有迁移。插件市场按真实加载情况和 host peer gate 区分不兼容与待重启，用户自行安装的插件保持原有归属及数据。

AnySearch 0.1.6 增加经审查的精确版本适配，恢复原生搜索、抓取、能力目录和高级/批量搜索。搜索数量按官网限定为 1–10，支持 json/markdown 内容格式；上游错误只保留安全状态和请求编号，不向模型或日志传递可能含凭据的错误原文。设置中新增十种语言的官网 API Key 申请链接、保存/移除和连接检查，复用 DSH 本地凭据存储，每次请求读取当前配置，无需重启。搜索结果仍须核验原始来源、属地、日期和适用性。

Codex CLI 升级到稳定版 0.160.0。桌面主对话可选择 DSH 或原生 Codex 执行；Codex 使用独立 App Server 持久线程，提供流式对话、多轮继续、停止、审批和问题答复。共享任务要求、专业提示、知识库与当前工作区，专业工具通过绑定当前会话的 Cordis 桥调用，沿用工具权限；同一任务只允许一个主执行者。原有 Codex 子智能体仍保留。登录继续采用隔离的 Codex 账户目录与原生浏览器授权。

专业任务插件修复首次客户需求未登记的问题，保留用户原话而不擅自推定目标。任务状态和原稿解析返回值省略可选空字段，符合新内核的无损 JSON 输出约束。

本次同版本修订接通主对话、本次任务、专业深度与专业化工作台的共享状态。工作台实际来源、阶段、发现和成果自动回写；切换页签持续接收更新，按真实主会话导航绑定项目。兼容既有任务记录省略的数组、成果标题和规范名称，避免本次任务空白。资料抽取与专业复核分别计数，工作台门禁与执行者登记进度分别展示，逐项审计问题按类型汇总并保留原始出处。

创建或绑定项目后，同一轮立即启用对应阶段工具。明确的主对话投标决策与工作台按钮走同一主机审批路径，关联真实用户消息及实际依据；已表达的阶段确认不再被登记成需要再次验收的要求。后序阶段入口遵守共同门禁，状态读取不会因时间戳变化使审批失效；子任务继承项目范围并合并贡献，不能改绑项目或替用户批准阶段。详见[专业任务引导](../docs/professional-task-guide.md)。

补通工作台成果的专业复核与要求关联；实际成果或冻结依据变化后，任务阶段同步显示待复核。旧任务缺少展示字段时兼容读取，运行中切换六个任务页签及工作台保持原生订阅，执行账本的具体工作重点在主对话、任务概览、顶部状态及工作台一致显示。

专业判断提示增加准确性优先、实质性反证、来源核验与计算/推断/惯例/框架/未知的区分、国别及版本适用性、未知前置、主动纠错和下游复核。模型记忆不能冒充本项目已核实依据，不编造文献及置信百分比；正式客户文件沿用业主和行业格式，分类用于工作底稿与审校，不默认逐句标签或附规则自查。该规则通过产品系统提示 section 注入，适用于普通和 Router Standard 预设。

本产品由 **Always π AI studio** 独立开发，许可为 **GPL-3.0-only**。

本次为用户授权的同版本本地重建。已完成主执行协议及界面回归、真实 DSH/PTC 专业工具联调、匿名搜索和隔离 Key 设置验证，以及完整 Office 加载检查；未使用真实 Codex 账户执行模型任务。安装包、校验文件与构建回执以此次重建产物为准。
