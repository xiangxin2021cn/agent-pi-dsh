# Agent Pi DSH 3.8.2

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.8.2","kernel":{"releaseTag":"dsh-v0.2.1-alpha.2","commit":"d743267388641bc76f17c45ce8b4c231aed1d32c"}} -->

本版升级 [官方 DSH 0.2.1-alpha.2](https://github.com/deepseek-ai/deepseek-harness/commit/d743267388641bc76f17c45ce8b4c231aed1d32c)，并整合大 DWG 修复、内嵌图像读取和专业任务联动。具体用法见 [3.8.2 使用指南](../docs/3.8.2-user-guide.md)。本文件是随源码提供的发布说明，下载及公开发布状态以 GitHub Release 实际资产为准。

## 主要改动

- 官方内核源码保持干净，使用匹配锁文件重新构建。纳入上游聊天折叠/滚动、会话切换高度、输入焦点、计划确认和模型可用性等改进，产品任务与工作台仍由插件层承载。
- 适配新版历史查询包位置及插件身份校验。专业任务的目标驱动与辅助 Codex 使用明确的产品实例，迁移既有启停和参数设置，避免覆盖被忽略后重复执行或丢失模型选择。
- 修复 DWG 解码位游标溢出造成的块名失真。用户验证图中的 1,111 条错误块名恢复，8,414 条 INSERT 与独立原生 CAD 清点一致。
- DXF 流式写盘；大型图纸使用磁盘索引和分页，保留原始组码及内嵌二进制。缓存核验原图、完整输出、引擎与代码版本，拒绝转换期间变动的来源。
- 支持逐个提取内嵌对象及 PNG。结构清点、普通查询、各个内嵌对象保留独立观察，避免后一次提取覆盖之前信息。
- CAD 解析警告、导出差异和未完成展开进入工程问题及任务发现；工程面板提供来源核查与内嵌图像入口。
- 更新 AnySearch、完整 Univer Office、产品 Codex 执行器及 PDF/Canvas 组件，详细版本、来源和验证见 [核心更新记录](../docs/3.8.2-core-plugin-updates.md)。
- 保留 Windows 开箱即用 BIM、投标响应对照和九个工程插件；旧工作流引用继续可恢复，插件关闭状态不因升级被擅自重置。

## 怎么使用

在主对话上传/引用图纸并描述目标，例如“核对这套图纸的构件和内嵌料表，先列完整覆盖清单，再按确认尺寸算量”。助手使用工程工具读取，将发现同步到“本次任务”和“专业化工作台”；需要查看内嵌内容时，从工作台打开图像并核对原图位置。

## 能力边界

块名修复、成功导出及内嵌提取都不等于全面算量。本图仍有警告 68、57 个三维实体和 22 条样条导出缺口，以及实例展开上限。97 个内嵌对象经核对为标识/联系方式，未发现钢筋料表。尺寸、单位、外参、专业语义和规则适用性继续逐项复核。

CAD 预览保留原 3.6.2 对应源码及构建身份；独立 patched host 另附精确构建回执、GPL 和 `Agent-Pi-DSH-3.8.2-CAD-host-corresponding-source.tar.gz`。Windows BIM 沿用已审核的 3.8.0 对应源码及运行库身份，未冒称重新编译上游二进制。
