# Agent Pi DSH 3.7.0

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.7.0","kernel":{"releaseTag":"dsh-v0.1.6-alpha.2","commit":"ddefc45fbc7f8e46dd73185e68295696d1297887"}} -->

Agent Pi DSH 由 **Always π AI studio** 独立开发和维护。

- 升级官方 DSH 内核至 `dsh-v0.1.6-alpha.2`，同步原生插件管理、侧栏预览与子智能体会话、文件变更审阅、启动诊断及多模态修复。
- 适配新版主对话与侧栏独立会话接口，保持主对话的知识库选择、专业深度和 Codex 执行绑定。
- 升级完整官方 Univer Office 插件至 0.3.2，采用官方连接参数、消息帧和原生依赖修复，保留文档、表格、演示文稿的编辑能力。
- 左栏底部换用 Always π AI studio Logo，适配展开与折叠状态。
- 保留 CAD、资源文件栏、可选 Agent Teams、手动模板和报告交付技能；普通对话仍按实际任务运行，知识库由用户显式选用。
- 已核查的插件市场 1.47.0、AnySearch 0.1.4 和模组注入器 0.3.3 维持当前版本。

CAD 对应源码沿用已验证的 `Agent-Pi-DSH-3.6.2-CAD-corresponding-source.tar.gz`，来源提交 `1aef6820ebc450125788158a4b2d1706115cdd10`。
项目及发行物采用 `GPL-3.0-only`，第三方组件保留原始条款。正式 SHA256 以同一 Release 中的 `.sha256` 资产为准。
