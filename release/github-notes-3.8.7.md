# Agent Pi DSH 3.8.7

本次更新继续分别维护主线和投标专版。主线保留原生 DSH 界面、专业工作台、知识库、用户模板 DNA、技能、完整 Univer 与后台智能体；投标专版保留独立界面、安装标识、数据目录和更新通道。

## 内核与核心组件

- DSH 固定官方 master 提交 `ce7073d51254c26cd63b22a60835b8f948deb447`，在原 alpha.2 基础上前进。上游 package 版本仍为 `0.2.2-alpha.2`，本版不虚构新的上游版本号。官网新发的 `0.2.1-rc.5` 属旧维护分支，不能按发布时间覆盖当前内核。
- Node.js 24.22.2 LTS、Electron 45.2.0、Codex CLI 0.166.0、Canvas 1.1.0、marked 18.1.2。
- 完整官方 Univer Office 0.3.9，保留原始发行包、授权材料、Gateway、Viewer、导入导出及原生计算与交换依赖；DSH Market 1.73.6。
- 保留经核验的 AnySearch、router、injector、Writing DNA 与 Windows BIM 运行时。详细来源及验收状态见同目录的 `3.8.7-core-components.json`。

## DWG 打开修复

3.8.6 可复现从其他项目工作台或引用打开 DWG 时，预览误用当前对话目录，返回 `path is outside the workspace`，没有进入解码器。3.8.7 修复 CAD 预览的来源项目关联：来源必须已登记在 Host 工作区列表中；有来源会话时验证其成员关系和 cwd，没有可用会话时只读预览，不自动创建空会话。返回预览保留各自来源，后端文件路径边界继续生效。

LibreDWG 保留已审核的 `0.7.10 + bit-cursor-fix.1`、converter 3.14.3 与 data-model 1.14.3 配套源码和二进制。新 `0.8.2` 的官方源码尚未包含本应用的大图位游标修复，不能直接用其 npm WASM 覆盖。此项是入口修复，不声称已经覆盖所有 DWG 版本、实体或用户原始故障图纸。

## 数据与回退

新内核的会话与投影格式保持兼容，原会话无需转成新格式。定时任务是独立变化：v1 可只读加载，首次编辑或投递后会写为 v2，旧版不支持 v2。

应用在启动新内核前，将默认 JSON 定时任务 v1 原始字节及 SHA256 收据一次性保存到各自 `dsh-home/.runtime-install/schedule-v1-before-3.8.7/`。后续启动不覆盖首份备份，完整性失败会阻止继续初始化。回退时先退出应用，再恢复该目录中的 `schedule.json` 到原 `storages/schedule.json`；升级后新增或编辑的定时任务不会出现在旧快照中。自定义 SQLite 存储应采用自己的数据库一致性备份。

上游新版模型定时工具可以管理整个宿主的任务，并且任务记录没有稳定的创建者字段。产品自带的标准、PTC 与 Cordis 预设因此暂不挂载这组扩大范围的模型工具，保留人类操作的原生定时任务页及既有任务。用户自定义预设原文件不改写。此项不影响章节编写、Univer、知识库或 DSH 后台执行。

升级开发及验收使用隔离数据，不操作原安装目录、原项目或真实会话，不调用模型服务。安装包及测试结果以本轮最终验证记录为准。
