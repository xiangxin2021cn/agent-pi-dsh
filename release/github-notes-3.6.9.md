# Agent Pi DSH 3.6.9

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.6.9","kernel":{"releaseTag":"dsh-v0.1.6-alpha.1","commit":"0a15e36e7f82b6ed45af6fa9759f29b40dcd965d"}} -->

Agent Pi DSH 由 **Always π AI studio** 独立开发和维护。

- 升级内置插件市场至 1.47.0、AnySearch 搜索至 0.1.4、模组注入器至 0.3.3；保留应用管理的 Teams、压缩组件和桌面重启适配。
- 普通对话和专业工作台通过 DSH 原生扩展补强任务规则：先看已有上下文，区分来源事实、用户决定、推算、建议及假设，按实际交付物选择技能。
- 新增按需加载的文件交付技能，强调真实格式、打开与版式检查、可编辑性和最终文件入口；专业深度增加 Office ZIP/CRC、PDF 解析及旧版 Office 容器检查，明确未验证范围。
- 改进报告创作识别，减少阅读、总结、翻译报告和诊断报错时误触发 huashu-report。
- 专业深度仍由用户启用并等待真实输入；知识库显式选用，模板由用户主动保存和选择。普通任务不强制进入投标或完整研判流程。
- 内核及其官方组件继续固定为最新已发布的 `dsh-v0.1.6-alpha.1`，不整体替换原生提示词；保留最新官方 Univer Office 0.3.0、Codex CLI 0.153.4、CAD、文件栏和可选 Agent Teams。

CAD 对应源码沿用已验证的 `Agent-Pi-DSH-3.6.2-CAD-corresponding-source.tar.gz`，来源提交 `1aef6820ebc450125788158a4b2d1706115cdd10`。
项目及发行物采用 `GPL-3.0-only`，第三方组件保留原始条款。正式 SHA256 以同一 Release 中的 `.sha256` 资产为准。
