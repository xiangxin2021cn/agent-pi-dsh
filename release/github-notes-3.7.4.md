# Agent Pi DSH 3.7.4

<!-- agent-pi-release-meta: {"schema":1,"appVersion":"3.7.4","kernel":{"releaseTag":"dsh-v0.1.7-rc.2","commit":"477b4f420553e8a52c2fbccc464d7561b239c443"}} -->

本版重点升级用户自主工作台和项目计划界面，DSH 内核保持官方 **0.1.7-rc.2**，不包含 RSI 实验功能。

- **自主修改工作台**：进入“专业化工作台 → 模块管理 → 自己新建工作台”，可新建、复制、修改和删除用户流程，增删阶段、调整依赖、选择技能、知识库及人工审批节点，并导入或导出流程 JSON。直接编辑不调用模型。内置流程通过复制后修改。
- **原生 DSH 插件架构**：工作台核心、知识库、投标、实施交付和投资拆分为五个插件，支持启停及开发者通过原生插件贡献领域模块。普通对话不默认启用投标流程或加载全部知识库。
- **项目流程保护**：既有项目使用创建时的流程快照；编辑保存检查版本，避免覆盖另一窗口的变更。停用模块后阻止新项目和新阶段执行，已有项目和成果仍可查看。
- **专业项目计划视图**：MPXJ 16.7.0 文件预览改为左侧层级任务表、右侧同步甘特图与底部任务详情。支持展开折叠、搜索、关键任务／里程碑／未完成筛选、日周月刻度、任务定位、依赖箭头及大计划可见行渲染。
- **手动修改和交付**：编辑名称、计划开始／完成、完成率及备注，支持撤销、重做和另存后回读校验。MPP 导出当前项目的 Project XML；P6 支持 XER／PMXML，导出保留全部项目。源文件不覆盖。
- **界面语言**：补充自主工作台的核心字段翻译，项目计划界面提供十种语言，改善阿拉伯语方向和窄窗口布局。其他产品界面仍有英文回退及待翻译部分。
- **保留现有能力**：完整 Univer Office 0.3.5、官方 Office 运行库 0.1.1、CAD、资源文件栏、可选 Agent Teams、Codex、专业深度、用户主动保存／选用模板及报告技能。

项目计划界面不包含自动排程、关键路径重新计算、资源平衡或基线对比。工期、关键标记、实际日期、依赖及资源来自源文件，部分字段只读。MPP 不能直接写回 `.mpp`，请用 Microsoft Project 打开导出的 XML 后另存为 MPP；导出后仍需复核 Project／P6 的日历、依赖、资源和软件特有字段。微信多图批次与跨轮图片引用问题不在本版完成范围内。AnySearch 0.1.6 继续按官方兼容检查处理，不绕过校验。

已验证 804 项任务的真实 MPP 副本，包含同步滚动、任务编辑、Project XML 导出回读及源文件保持；自主工作台、原生插件启停、项目快照及附件相关回归通过。打包继续执行官方依赖准备、运行时完整性、Office／CAD 来源校验和启动诊断流程。

升级前完全退出 Agent Pi DSH。Windows 建议使用默认或较短安装目录。校验值以同一 Release 的 `.sha256` 文件为准。

本产品由 **Always π AI studio** 独立开发，发行许可为 **GPL-3.0-only**；对应 CAD 源码归档随 Release 提供。
