# Agent Pi DSH 3.5.1 — 执行账本与双态控制面板

3.5.1 修复主对话与专业工作台互不理解的问题。DSH 主智能体仍是唯一负责语义判断、任务分解和子智能体派活的“大脑”；控制面板不再假装独立智能体，也不再仅凭文件数量机械推进，而是同时呈现主智能体回写的执行态和系统从磁盘核验的事实态。

DeepSeek Harness 仍固定在 **`dsh-v0.1.2-alpha.1`**（`cd5ef81481`），未修改官方内核源码。

## 核心改动

- 每个会话新增持久化 `execution-ledger.json`，记录当前目标、批次、计划、子任务分派、阻塞、下一动作和心跳版本。
- 主智能体通过 `execution_update` 主动回写执行状态；工作台只展示，不复制第二套计划器。
- 控制面板分成“执行态（主智能体回写）”和“事实态（系统核验）”，并显式列出两者的认知差异。
- “继续推进”优先发送精简的差异对齐任务，只补齐未完成计划、磁盘变化和阻塞，不重复注入整阶段长提示词。
- 人工决策阻塞会停止自动推进；阶段提交成功后，同阶段执行账本同步收口。
- 执行摘要与阶段记忆均以磁盘为业务基线，避免主对话因重复塞入长报告而撑爆上下文。

## 官网参赛版收敛

- 官网首页、文档、隐私页和签名说明页移除 GitHub、源码仓库、镜像与 Classic 源码入口。
- 页首、下载区和页尾版本统一为 3.5.1。
- 官网不再请求外部 Release API，参赛包改为线下直接分发说明。
- 签名说明如实标记当前 Windows 参赛安装包未签名，并要求以 SHA256 校验。

## 验证重点

- 同一会话的执行账本可持久化，纯心跳不增加业务修订号，计划或阻塞变化才增加修订号。
- 主会话 ID 被带入系统核验和继续推进请求，不会把其他会话的计划误显示为当前计划。
- 真实 React DOM 中同时出现执行态、事实态、计划、分派和差异提示。
