# Professional Report Writing

Write a paper a named reader can act on. The first paragraph must carry the judgment. Evidence follows. Gaps stay gaps.

## When to use / when not to

**Use** for research reports, analysis reports, due-diligence reports, and management briefs that a human will read to decide, brief, or file.

**Do not use** for:

- Tender BOQ workpapers, parse memos, methodology, programme narratives, or employer returnables — use `tender-formal-writing`.
- Chat replies, status pings, or code.
- Contractual correspondence (letters, emails) — the editorial profile already owns that shape.

## Operating sequence

1. Read the editorial profile **reader decision**. If none is given, infer one sentence: what the reader must be able to do after this paper.
2. Outline only the sections that serve that decision. Do not invent a textbook TOC.
3. Write judgment first, evidence second. Every material claim needs a locator, a number, or an explicit gap.
4. Run the self-check below before handing off. Do not “polish” by adding filler.

## Genre recipes

| Genre | Shape |
|---|---|
| Research | Scope → method → findings → limitations. Recommendation only if the evidence supports it. |
| Analysis | Claim → evidence → implication. One material finding per section. |
| Diligence | Proceed / revise / stop, then material risks and unresolved conditions. |
| Management brief | Decision, basis, next action. Stay within 10 headings. |

## Forbidden

Do not use chatbot scaffolding or marketing diction. If a sentence could appear in any other job, delete it.

Typical rejects:

- English filler: Furthermore; Moreover; It is important to note; In conclusion; leverage; robust; seamless; cutting-edge; key takeaways
- Chinese filler: 综上所述；值得注意的是；赋能；全方位；一站式；确保万无一失；全面覆盖；助力；深度剖析
- Skeleton: Key Takeaways; 首先…其次…最后确保
- Catalog / pack-path tours: `documentId`; Working Folder; Agent Pi Outputs; orchestration/briefs; pack 路径
- Inventing a textbook TOC the reader did not ask for

**Do not install marketplace skills, run `npx skills`, or fetch skills.sh.** If this skill is missing, keep the short writing ban and continue. Never search a public registry from a formal path.

## Good vs bad

**Good** (claim + locator + gap):

> Particular Conditions 8.7 sets delay damages at 0.05% of the contract sum per day, capped at 10%. Pricing must carry that cap in the risk allowance. Addendum 2 does not say whether night closures are compensable; leave the traffic-accommodation rate open until that is clarified.

**Bad**:

> 综上所述，本报告将全方位覆盖评标要点。Furthermore, it is important to note that our robust approach ensures a seamless outcome.

## Self-check

Before handing off:

- Zero filler hits from the forbidden list
- At least one judgment verb (因此 / 所以 / 应 / 不得 / 须 / 缺口 / 风险是 / implies / must / shall not / gap)
- No `documentId`, Working Folder, or pack-path tour in the reader-facing body
- Gaps left as gaps; do not paper over missing evidence with fluent prose
